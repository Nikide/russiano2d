# Russiano2D: сначала доки, потом код

## 0. Загрузи память
Прочитай заметки `r2d-*` из памяти (конституция, правила, контракт модуля).

## 1. Читай (целиком, по порядку) ДО первой правки в src/
1. docs/ARCHITECTURE.md
2. docs/AGENT_IMPLEMENTATION_RULES.md
3. docs/API.md
4. docs/HIGH_LEVEL_API.md
5. при правке src/highlevel/**: docs/highlevel/_CONTRACT.md + docs/highlevel/<модуль>.md
6. по теме: PHILOSOPHY, UI_RMLUI_LAW (любой UI), TESTING, RECORD_REPLAY, DEVTOOLS, ROADMAP/TASKS
Хук `.claude/hooks/r2d_gate.py` блокирует Edit/Write в src/ пока это не прочитано целиком.

## 2. Найди существующее
Grep по теме, прочитай код, его доку и тесты (tests/js, tests/agent). Дубль подсистемы — недопустим.

## 3. Блокеры — остановись и доложи (не импровизируй)
- нужна смена архитектуры (C++, ECS, замена QuickJS/SDL/RmlUi, второй UI, редактор сцен);
- надо сломать публичный API;
- нет зависимости;
- тесты падают ДО твоих правок;
- фича дублирует существующую;
- доки и код расходятся так, что влияет на дизайн.
Дай конфликт + минимальное совместимое решение.

## 4. Жёсткие запреты
ImGui-окна; новые меню на `<ui.*>`; `new/extends/this` в игровом коде; поштучные C↔JS в горячих путях; выдуманная диагностика (только факты движка); «стало быстрее» без замера; `def()` с занятым именем метода; engine.* на верхнем уровне модуля.

## 5. Цикл
короткий план → тесты → наименьший вертикальный срез → `cmake --build build` → `python3 tools/run_tests.py` + `tests/js` (qjs) + стражи доков → headless-сценарий → замер (если перф) → доки в ТОМ ЖЕ изменении (закрытый пункт убрать из TASKS/ROADMAP) → CHANGELOG.
Не коммитить без просьбы. Доки по-русски, код по-английски.

# Статус веб-сборки

В этом checkout нет активного Emscripten exporter или поддерживаемого web
runtime. Старые инструкции smoke-прогона относились к удалённому прототипу и
не должны использоваться для проверки текущего движка.

Поддерживаемые сейчас пользовательские сборки: macOS arm64, macOS x86_64 и
Windows x86_64 в релизах, а также сборка Linux на целевой системе. Команды и
требования приведены в [BUILD.md](../../docs/BUILD.md).

Веб-экспорт можно вернуть отдельной задачей после появления поддерживаемого
exporter, runtime-фикстуры, smoke-команды и документации. До этого лендинг и
релизный процесс не рекламируют браузерный запуск.

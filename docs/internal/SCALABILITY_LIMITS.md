# Russiano2D: ёмкости, бюджеты и оставшиеся пределы

Документ отвечает на один вопрос: **почему в движке остался каждый `MAX_*`, и
является ли он пределом мира или только текущим размером массива.**

Правило проекта:

> **Ёмкость — не бюджет.** Мир может содержать 50 000 объектов, но кадр не
> обязан рисовать, симулировать, загружать и затенять все 50 000.

Поэтому реестры ресурсов растут динамически, а дорогая работа ограничивается
бюджетами качества (top-N, вытеснение, отложенная загрузка). Жёсткие пределы
остались только там, где их требует формат, железо, алгоритм или безопасность.

## 1. Как читать имена

| Шаблон | Значение |
|---|---|
| `MAX_*` | настоящий максимум (формат/алгоритм/безопасность), обходить нельзя |
| `*_INITIAL` | стартовая ёмкость динамического массива, не потолок |
| `DEFAULT_*` | значение по умолчанию, настраивается |
| `*_BUDGET` | бюджет дорогой работы на кадр/представление |
| `*_SAFETY_*` | защита парсера/API от повреждённых или абсурдных данных |
| `*_CAP` | ёмкость статического массива, который не является мировым лимитом |

## 2. Динамические реестры (потолка контента нет)

| Реестр | Рост | Идентификаторы | Телеметрия |
|---|---|---|---|
| Текстуры | пул слотов, удвоение от 64 | id = слот, freelist | `engine.limits().textures/_max`, `r2d_texture_peak` |
| Тела физики | пул слотов, старт 1024 | id = слот + поколение | `r2d_physics_stats` |
| Суставы | пул слотов, старт 64 | id = слот + поколение | `r2d_physics_stats` |
| События контакта | буфер 128 → 256 → … | — | `contact_events_max`, `contact_oom` |
| Звуковые ассеты | динамический массив + hash путей | стабильный id | `r2d_audio_sound_count` |
| Звуковые шины | динамический массив от 8 | слот переиспользуется | — |
| Материалы Re2D | динамический массив от 64 | `uint16`-совместимый id | `world.info().materialCount` |
| Свет Re2D | динамический массив от 128 | opaque token (слот+поколение) | `world.info()` |
| Декали Re2D | динамический банк | opaque token | `decalCount/decalCapacity/decalEvicted` |
| Акторы/атласы Re2D | динамические массивы | стабильные индексы | `world.info().actorCount/...` |
| Hit proxies/триггеры/моверы/контроллеры | динамические массивы | стабильные индексы | `world.info()` |
| Particles | ring/free-list, ёмкость задаётся при init | индекс в пуле | `particles_count/capacity`, budget |
| VFX pools | ёмкости из `R2DWorldVfxQuality` | индекс пула | `r2d_world_vfx_info` |
| Подписчики SDL | 8 → рост | индекс | — |
| Обработчики `ui.on` | 256 → рост | слот | `$.debug.limits().ui_callbacks_max` |
| Текстовые буферы | 1 КиБ → рост | — | — |
| Пакеты груза | индекс путей (hash) | — | `r2d_payload_lookup_stats` |

## 3. Настоящие пределы (остались осознанно)

### Формат / алгоритм

| Предел | Где | Почему |
|---|---|---|
| `R2D_MAX_POLY_POINTS = 8` | `src/physics.h` | Выпуклый полигон Box2D; сложная геометрия разбивается на несколько форм при авторинге |
| `R2D_MAX_SHAPES_PER_BODY = 8` | `src/physics.h` | Число форм, читаемых за один запрос `b2Body_GetShapes`; тело может иметь несколько форм, но API возвращает до 8 за раз |
| 128 слотов в bake-формате света | `src/re2d_world_bake.c` | Формат запечённого света исторически 128-слотовый; рантайм-реестр при этом динамический |
| `R2D_WORLD_LIGHT_TOKEN_STRIDE` (17 бит слота) | `src/re2d_world.h` | Упаковка непрозрачного токена в положительный int для JS |
| `R2D_MAX_QUERY = 256` | `src/physics.h` | Размер результата одного запроса, а не число тел в мире; вызывающий передаёт свой буфер |

### Железо / бэкенд

| Предел | Где | Почему |
|---|---|---|
| 16384×16384 при создании текстуры | `r2d_texture_create_rgba` | Верхняя страховка до проверки бэкенда; реальный отказ придёт из `SDL_CreateGPUTexture` с явной ошибкой |
| `R2D_WORLD_MATERIAL_TEXTURE_MAX = 4096` | `src/re2d_world.h` | Политика ассетов проекта для PNG материалов/неба; GPU-предел проверяется отдельно |
| Лимиты uniform/storage-буферов, MRT, сэмплеров | SDL_GPU / драйвер | Запрашиваются у бэкенда, не выдумываются движком |

### Безопасность (парсер/API, не мир)

| Предел | Значение | Почему |
|---|---|---|
| `R2D_PAYLOAD_MAX_RAW` | 4 ГиБ | Повреждённый заголовок не должен просить гигабайты; путь миграции — payload v3 (`docs/internal/PAYLOAD_V3.md`) |
| Число файлов в грузе | 100 000 | Явная ошибка формата вместо молчаливого переполнения |
| Строка текста | safety 4 МиБ на буфер | Защита от бесконечного/повреждённого ввода; растёт от 1 КиБ |
| Частиц за один `emit` | 1 000 000 | Защита от сломанного скрипта/цикла, не лимит мира |
| Слотов пула | 2²⁶ | Защита от запроса таблицы в десятки ГиБ |
| Обработчики UI | 2²⁰ слотов | Защита от утечки подписок |
| Манифест/EXR/архив | см. `docs/internal/` | Значения можно поднять в проекте, но не отменять без замены |

### Дизайн (осознанное ограничение)

| Предел | Значение | Почему |
|---|---|---|
| Дорожек музыки (stems) | 8 (`R2D_STEM_LIMIT`) | Один transport, 8 слоёв — это модель музыкальной системы, а не размер массива |
| Геймпады | 4 | Разумный размер локальной игры вчетвером |
| Касания | 10 | Разумное число одновременных пальцев |
| Viewport'ы | 8 | Слоты render target; слоты текстур при этом динамические |
| Эффекты на узле | 64 | Бюджет на кадр, синхронизирован с JS-слоем |
| Пользовательские шейдеры | 16 | Набор слотов пайплайнов на кадр |

## 4. Бюджеты кадра (настраиваются)

| Бюджет | По умолчанию | Где |
|---|---|---|
| Одновременные голоса звука | 128 | `R2D_DEFAULT_AUDIO_VOICES`, `r2d_audio_set_voice_budget` |
| Свет на span (top-N по вкладу) | 16 | `R2D_WORLD_LIGHTS_PER_SPAN` |
| Затеняемые света (ranking) | 16 | `R2D_WORLD_MAX_SHADOWS` |
| Рендер декалей | 128 | `r2d_world_decal_budget` |
| Частицы (ёмкость/бюджет) | 2048 runtime, 8192 legacy pool | `r2d_world_particles_set_capacity` |
| VFX-карты/трейлы/свет | 128/32/16 | `R2DWorldVfxQuality` |
| Загрузка стриминга | байты/элементы за кадр | `R2DStreamingBudget` |
| Асинхронные задания | 256 jobs / 256 МиБ / 64 ready | `R2DAsyncLimits` |

Эти числа не делают контент невозможным: при исчерпании движок выбирает top-N,
вытесняет по приоритету/возрасту или переносит работу на следующие кадры.

## 5. Диагностика

* `engine.limits()` / `$.debug.limits()` — занятость и текущая ёмкость.
* `r2d_physics_stats`, `r2d_texture_upload_stats`, `r2d_font_upload_stats`,
  `r2d_audio_stats`, `r2d_async_pressure`, `r2d_payload_lookup_stats`,
  `r2d_world_vfx_info`, `world.info()` — счётчики/пики для debug-страницы.
* Ошибки бюджета называют: что не удалось, текущее значение, предел, причину
  и является ли он настраиваемым.

## 6. Что осталось на будущее

* Payload v3 (chunked/random-access) — формат спроектирован в
  `docs/internal/PAYLOAD_V3.md`, сериализация ещё не реализована.
* LRU-вытеснение страниц шрифтового атласа: страницы создаются, старые не
  освобождаются, пока на них ссылаются спрайты глифов.
* Адаптивные бюджеты стриминга по времени кадра.
* PGO/микрооптимизации после профилирования.

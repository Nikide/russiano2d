# Обучение embedding-модели R2D на Cloud.ru

Статус: **инструменты готовы, обучение не запускалось** — метрик дообученной модели нет.
База: [`intfloat/multilingual-e5-small`](https://huggingface.co/intfloat/multilingual-e5-small)
(~118M параметров, RU/EN). Выбрана как кандидат по размеру и языкам; бенчмарк с другими
кандидатами (bge-m3, Qwen3-Embedding) ещё не проводился.

## Что нужно

* GPU-машина или ноутбук на Cloud.ru (достаточно одной карты: модель маленькая; порядок — минуты на эпоху).
  Тип машины и её стоимость выбирает владелец аккаунта: запуск тратит деньги, поэтому делается вручную или с явным «да».
* Доступ в консоль/SSH — **только у вас**. Ключи и токены в репозиторий, логи, `project.json`,
  скрипты и сообщения не попадают; при необходимости передаются переменными окружения на самой машине.
* Cloud.ru здесь — только вычисления. Хранилище, индекс и поиск живут локально.

## Шаги

1. Локально (без GPU) подготовить пары:
   ```bash
   python3 tools/ai/build_pairs.py          # tools/ai/data/{train,val,test}.jsonl
   ```
2. Скопировать на машину `tools/ai/` и `tools/ai/data/` (scp/rsync/веб-консоль).
3. На машине:
   ```bash
   pip install -r tools/ai/requirements.txt
   python3 tools/ai/eval_embed.py --data tools/ai/data --model intfloat/multilingual-e5-small   # база
   python3 tools/ai/train_embed.py --data tools/ai/data --out runs/e5-r2d
   python3 tools/ai/eval_embed.py --data tools/ai/data --model runs/e5-r2d                      # после
   ```
4. Забрать `runs/e5-r2d` (≈ 470 МБ) и два JSON с метриками; машину **остановить/удалить**.
5. Сравнивать recall@1/5/10 и MRR «до» и «после»; улучшение заявлять только по этим числам.

## Ограничения данных

Пары синтетические (заголовок → раздел, описание `$`-API → имя+описание, название/описание/теги кирпичика → его карточка), без LLM и без
живых вопросов; описания сгенерированы по именам и бывают шаблонными. Это стартовый
сигнал: модель может выучить стиль доков, а не вопросы людей. Для «доучивания своими
силами» добавляйте реальные RU/EN-вопросы в `train.jsonl` (формат: `query`, `positive`,
`source`, `kind`) и повторяйте шаги 3–5. Разбиение train/val/test — по файлам и путям API,
чтобы тест не пересекался с обучением.

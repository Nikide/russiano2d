# Навык: дизайн уровней и баланс

## 1. Структура уровня

1. **Безопасный старт:** первые секунды без угроз — игрок осваивает управление.
2. **Обучение через ситуацию:** новую механику вводишь в безопасном месте (прыжок над ямой без шипов), затем усложняешь, затем комбинируешь.
3. **Нарастание:** сложность растёт волной (напряжение — передышка — напряжение), а не прямой.
4. **Цель видна заранее:** выход/босс/ключ показан или намечен рано, чтобы игрок понимал, куда идти.
5. **Награда за исследование:** секреты (`world.secret-area`), бонусы вне основного пути.
6. **Финал:** кульминация (босс, самый трудный проход) и явное завершение (`world.level-exit`, `ui.result-screen`).

Длина первого уровня — 1–3 минуты. Лучше три коротких и разных уровня, чем один длинный и однообразный.

## 2. Тайлы и карты

| Способ | Когда |
|---|---|
| Объекты в коде (`<wall>` и др.) | прототип, до ~20 элементов |
| Тайловая карта: `world.tilemap-layer`, `world.tilemap-collision`, `world.breakable-tiles`, `world.one-way-platform` | уровни побольше |
| Карта в студии Hammer (`.re2dmap` → `r2d world-compile`) | 2.5D / от первого лица |
| Комнаты: `world.streamed-room`, `camera.room-lock`, `world.scene-entry/exit` | метроидвания, подземелья |

Для карты не придумывай формат — используй студию (`studio_ops` вкладки) и `studio_save`.

## 3. Баланс — через числа, не на глаз

Выписывай ключевые числа в начале и держи их в одном объекте-конфиге (`const TUNING = { speed, jump, hp, damage, spawnDelay }`),
чтобы подкручивать без охоты по коду.

| Величина | Хорошее начало |
|---|---|
| Здоровье героя | 3–5 «ударов» врага |
| Урон врага | 10–25% здоровья героя за удар |
| Здоровье врагов | убивается 1–3 попаданиями (босс 20–40) |
| Неуязвимость после урона | 0.6–1 с |
| Награда | чуть выше риска: подбор у опасного места ценнее |
| Скорость врага (обычного) | 40–70% скорости героя |
| Время реакции на опасность | ≥ 0.5 с от предупреждения до удара |

Проверка баланса — `playtest`: пройти уровень сценарием, собрать `eval` метрик (потеряно здоровья, время, собрано), поправить 1–2 числа,
повторить. Менять **одно число за раз**.

## 4. Чек-лист перед «готово»

- [ ] Уровень проходим (сценарием `playtest` дойти до выхода).
- [ ] Нет «безвыходных» ям: падение возвращает на чекпоинт (`kit.platformer-checkpoint`).
- [ ] Первый враг появляется после того, как игрок научился двигаться.
- [ ] Видна цель (подсказка `kit.tutorial` или `ui.quest-tracker`).
- [ ] Есть момент передышки и момент напряжения.

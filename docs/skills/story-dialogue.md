# Навык: сюжет, диалоги, визуальная новелла

## 1. Что использовать

| Нужно | Инструмент |
|---|---|
| Визуальная новелла целиком | `kit.visual-novel`; маршруты — `kit.romance-routes`; готовая основа — `kit.project-vn-romance`; в проекте — шаблон VN (`templates`, `docs/VN_MAKER.md`) |
| Диалог с выбором в игре | `dialogue.tree`, `dialogue.choice`, `dialogue.typewriter`, `dialogue.auto-advance`, `dialogue.condition`, `dialogue.action`; окно — `ui.dialogue-box`, `ui.choice-list` |
| Флаги и счётчики сюжета | `story.flag`, `story.counter`, `story.choice-history`, `story.chapter` |
| Концовки и маршруты | `story.relationship-route`, `story.ending` |
| Сохранение сюжета | `save.story-state`, `kit.episodic-story` |
| Проверка | `r2d story …` (labels, goto, говорящие, ассеты, i18n) и `r2d dialog …` (RML/RCSS) — через `r2d_cli` |

## 2. Структура истории

1. **Крючок:** в первой сцене — вопрос или конфликт.
2. **Выбор имеет последствия:** каждый выбор меняет флаг/счётчик (`story.flag`), и это отражается позже (реплика, сцена, концовка). Выбор без
   последствий — иллюзия, игрок заметит.
3. **Ветвление ограничено:** 2–3 ветки, которые сходятся в общих точках; иначе объём растёт экспоненциально.
4. **Концовки:** 2–4, зависят от накопленных флагов; проверь, что каждая достижима.

## 3. Диалог

* Реплика — 1–2 предложения (до ~140 символов), один говорящий, ясный характер голоса.
* Выборов 2–4, короткие. Вариант «молча уйти» полезен, если нужен нейтральный выход.
* Не перегружай экспозицией: информацию подавай по крупицам, привязывая к действию.
* Тексты держи в данных (сценарии, `$.i18n`), а не в коде: потом можно локализовать (`localization.*`).

## 4. Проверка

* `r2d story validate` — битые `goto`, метки без цели, неизвестные говорящие, отсутствующие ассеты.
* Пройди каждую ветку `playtest`-ом или по сценарию: флаг выставлен → нужная реплика/концовка достижима.
* Нет ли тупика: у каждого узла есть следующий узел или явный конец.

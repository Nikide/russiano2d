# Навык: генерация звуков

Инструмент — `generate_sound` (в игре — `$.sfxgen`, в CLI — `r2d sfx-gen`). Конвейер: **описание словами или пресет → дескриптор R2D SFX
→ процедурный синтез → WAV** (44100 Гц, моно, 16 бит). Это синтезатор в стиле sfxr/rFXGen: монеты, выстрелы, взрывы, прыжки, удары,
клики, сирены. **Музыку, речь и «реалистичные» звуки он не делает** — для них нужны готовые файлы.

## 1. Рабочий цикл

1. Подбери тип звука. Быстрее всего — одной фразой: `generate_sound { path: "assets/sfx/jump.wav", text: "короткий высокий прыжок" }`.
   Опознаются: монета/подбор, выстрел/лазер, взрыв, бонус/усиление, удар/урон, прыжок, клик/выбор. Не опознано — ошибка со списком;
   тогда задай `preset` или `params` (рецепты ниже).
2. Прочитай ответ: длительность, пик, высота тона и **огибающая** (слева направо — время, выше — громче). Слуха у тебя нет, поэтому
   сверяй с ожиданием: выстрел — резкая атака и быстрый спад; бонус — тон растёт; взрыв — шум и длинный хвост.
3. Не нравится — меняй **одно**: другой `seed` (другой вариант того же типа), `mutate: 0.2` (вариация), или точечно в `params`.
4. Играй: `$.sound.play('assets/sfx/jump.wav')`. Несколько вариантов одного события (шаги, удары) — банк:
   `$.sfxgen.bank('hit', ['hurt', { preset: 'hurt', seed: 2 }, { preset: 'hurt', seed: 3 }])`, затем `$.sfx.play('hit')` — звук не приедается.
5. Файл создан `generate_sound` → откат — `undo_edit`. Существующий файл заменяется только с `overwrite: true` (откат тогда невозможен).

В самой игре можно не хранить файлы: `$.sfxgen.play('coin')` сгенерирует звук один раз (кэш `sfxgen_cache`) и сыграет. Для собранной игры
надёжнее заранее записать WAV в `assets/sfx/`.

## 2. Пресеты

| Пресет | Звук | Для чего |
|---|---|---|
| `coin` | короткий высокий «дзынь», иногда с подскоком тона | монета, подбор |
| `laser` | быстро падающий тон | выстрел, лазер |
| `explosion` | шум с хвостом | взрыв, разрушение |
| `powerup` | растущий тон | бонус, улучшение |
| `hurt` | резкий шум/квадрат с падением | удар, урон |
| `jump` | растущий квадрат | прыжок |
| `blip` | очень короткий писк | клик, выбор в меню |
| `random` | случайный | поиск идей (сначала `seed` перебором) |

## 3. Что значит каждое поле `params`

| Поле | Что делает | Как крутить |
|---|---|---|
| `wave` | форма: `square` (резкий «8-бит»), `saw` (жужжащий), `sine` (мягкий), `noise` (шипение, взрывы) | шум — для ударов и взрывов |
| `freq` | стартовая высота 0..1 (0.2 — низкий, 0.5 — средний, 0.8 — писк) | |
| `slide` | высота растёт (>0) или падает (<0) | прыжок/бонус >0, выстрел/удар <0 |
| `minFreq` | при падении до этой высоты звук обрывается | ограничивает «падающий» звук |
| `attack`, `sustain`, `decay` | нарастание, удержание, спад; длина ≈ их сумма | клик: sustain 0.02, decay 0.08; взрыв: decay 0.4+ |
| `punch` | всплеск громкости в начале | удару и взрыву 0.3–0.6 |
| `changeAmount`, `changeSpeed` | скачок высоты через время («дзынь-дзынь») | монета, бонус |
| `vibratoDepth`, `vibratoSpeed` | дрожание высоты | сирена, привидение |
| `duty`, `dutySweep` | ширина импульса квадрата (тембр) | 0.5 — «пустой», 0 — «нос» |
| `repeat` | перезапуск высоты внутри звука | бонус, тревога |
| `lpf` | срез высоких (1 — выкл., 0.3 — глухо) | глухие удары, взрыв издалека |
| `hpf` | срез низких (0 — выкл.) | тонкий щелчок |
| `phaserOffset`, `phaserSweep` | «рябь» | лазер, магия |
| `volume` | общая громкость 0..1 (по умолчанию 0.5) | |

## 4. Рецепты (готовые `params`, проверены)

```json
{ "name": "coin", "params": { "wave": "square", "freq": 0.55, "sustain": 0.05, "decay": 0.25, "punch": 0.4, "changeSpeed": 0.6, "changeAmount": 0.4 }, "seconds": [0.08, 0.3] }
```
```json
{ "name": "jump", "params": { "wave": "square", "freq": 0.3, "slide": 0.25, "sustain": 0.15, "decay": 0.2, "duty": 0.5 }, "seconds": [0.08, 0.4] }
```
```json
{ "name": "shot", "params": { "wave": "saw", "freq": 0.7, "minFreq": 0.2, "slide": -0.4, "sustain": 0.1, "decay": 0.25 }, "seconds": [0.04, 0.3] }
```
```json
{ "name": "boom", "params": { "wave": "noise", "freq": 0.25, "slide": -0.2, "sustain": 0.2, "decay": 0.45, "punch": 0.5, "lpf": 0.5, "volume": 0.4 }, "seconds": [0.3, 1.2] }
```
```json
{ "name": "step", "params": { "wave": "noise", "freq": 0.6, "sustain": 0.03, "decay": 0.15, "lpf": 0.3 }, "seconds": [0.02, 0.2] }
```
```json
{ "name": "click", "params": { "wave": "square", "freq": 0.45, "sustain": 0.04, "decay": 0.1, "hpf": 0.1 }, "seconds": [0.01, 0.15] }
```
```json
{ "name": "siren", "params": { "wave": "sine", "freq": 0.2, "sustain": 0.35, "decay": 0.3, "vibratoDepth": 0.3, "vibratoSpeed": 0.4 }, "seconds": [0.3, 1.5] }
```
```json
{ "name": "powerup", "params": { "wave": "square", "freq": 0.35, "slide": 0.15, "repeat": 0.5, "sustain": 0.25, "decay": 0.35 }, "seconds": [0.2, 1.0] }
```

Подставь рецепт как `params` (без `name` и `seconds`) и поправь `seed`/поля под игру: монета для «магического» мира — `wave: "sine"`,
выстрел тяжелее — ниже `freq` и `lpf: 0.6`, удар — добавь `hpf: 0.2`.

## 5. Куда какой звук

| Событие | Звук | Подсказка |
|---|---|---|
| Прыжок, приземление | `jump`, `blip` (приземление тише) | не длиннее 0.3 с |
| Подбор | `coin` (разные seed для разных предметов) | высота растёт с ценностью |
| Урон герою | `hurt` + тряска (`game-feel`) | отличай от урона врагу выше/ниже |
| Выстрел | `laser` или рецепт `shot` | на частую стрельбу — банк из 3–4 seed |
| Взрыв, смерть босса | `explosion` | `lpf` ниже — «издалека» |
| Интерфейс | `blip` | тише эффектов (volume 0.3) |
| Победа / бонус | `powerup` | |

## 6. Ловушки

* **Тишина или обрыв:** сумма `attack+sustain+decay` слишком мала, `minFreq` выше стартовой частоты — звук обрывается сразу. Ответ покажет `seconds`.
* **Срез:** `clipped > 0` — уменьши `volume`.
* **Всё звучит одинаково:** меняй `seed`, а не только поля; для одного события делай банк вариантов.
* **Громкость:** игровые эффекты 0.4–0.7, интерфейс 0.2–0.4. Музыку (файл) держи тише эффектов.
* Не клади сгенерированный WAV поверх существующего файла игрока без `overwrite`.
* Синтезатор детерминирован: одинаковые `params` + `seed` — одинаковый звук; хешем кэша `$.sfxgen` служит содержимое дескриптора.

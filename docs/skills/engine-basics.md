# Навык: основы движка — идиомы `$` и частые ловушки

Загружай перед первой правкой кода игры. Только публичный `$` API; не пиши второй движок, ECS, свой scene graph, event bus и «менеджеры».
Имя `$.…`, в котором не уверен, проверь `api_lookup` один раз — не гадай.

## 1. Каркас

```js
$.ready(($) => {
    $.gfx.color('#141824');
    $.world.gravity(0, 1800).bounds(0, 0, 1280, 720);   // bounds — невидимые стены по краям; без них герой улетает за уровень
});
```

Сцены: `$.scene.add('level', ($) => { … })` и запуск `$.scene.load('level')`. Строку `import "./generated/snippets/index.js"` добавляет
генератор кирпичиков — сам её не пиши.

## 2. Физика есть только у видов узлов

* Герой: `$('<player>', { id: 'hero' }).at(200, 300).size(26, 30).color('#e07040').controls({ axis: 'both', coyote: 100, jumpBuffer: 120 }).collision(26, 30).appendTo($.world)`.
* Земля и платформы — **твёрдые** `<wall>`: `$('<wall>', { id: 'p1' }).at(x, y).size(200, 24).color('#5a6a5a').appendTo($.world)`.
* Голый `<sprite>` — просто картинка: без гравитации и столкновений, герой пройдёт сквозь.
* Монета — `$('<sprite>', { id: 'coin1' }).at(x, y).size(18, 18).color('#ffd040')` плюс кирпичик `interact.pickup`.
* Картинка: `$('<sprite>', { src: 'assets/a.png', w: 64, h: 64 })`.

## 3. Кирпичики вместо кода

Готовое поведение (движение, прыжок, AI, способности, камера, UI) **не пиши кодом**: `snippet_find` → `snippet_apply`. Наборы `kit.*`
(например `kit.platformer-core`: движение + здоровье + камера) подключают сразу несколько кирпичиков — предпочитай их. Искать достаточно
2–3 раза, потом действуй; `snippet_find` — с одним словом, каталог целиком (`snippet catalog`) не запрашивай — это 500 кирпичиков.

* Объект для кирпичика создай в коде с **литеральным** `id` (`id: "coin1"`), не в цикле с id из строки — граф их иначе не увидит;
  затем `snippet_apply` с `owner: "object:<id>"`.
* `interact.pickup` шлёт на герое событие `collect` с `{ value }`.

## 4. Текст и счёт

```js
const label = $('<text>', { text: 'Счёт: 0', size: 32 }).at(40, 40).appendTo($.world);
hero.on('collect', (e) => { score += e.value || 1; label.text('Счёт: ' + score); });   // так обновляется текст
```

## 5. Вид от первого лица / 2.5D

Новый API — `$.re2dWorld` (`docs_show highlevel/re2d`, навык `fps-2-5d`). `.kind(Re2D)` и `$.camera.kind` — legacy, не используй.
Не оборачивай вызовы в `try/catch`: ошибки должны быть видны.

## 6. Проверка

После записи `.js` линт уже запущен — исправь замечания. После изменения сцены — `screenshot_check` (`КАДР ПУСТОЙ` — игра не работает,
ищи причину). Для логики — `playtest`; в конце `r2d_validate`. Не повторяй проверки без правок.

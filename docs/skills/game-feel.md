# Навык: «сочность» (game feel)

Одинаковая механика с эффектами ощущается как другая игра. Правило: **каждое важное событие (удар, подбор, смерть, прыжок, победа)
получает отклик минимум в двух каналах** — видно + слышно (+ тряска для сильных).

## 1. Что звать

| Канал | API / кирпичик | Когда |
|---|---|---|
| Тряска камеры | `$.camera.shake(...)`, кирпичики `camera.screen-shake`, `camera.trauma` (накапливаемая, затухает) | урон герою, взрыв, приземление с высоты |
| Остановка кадра | `$.vfx.hitStop(...)`, `animation.hit-pause` | сильный удар (50–90 мс) |
| Вспышка | `$.vfx.flash(...)`, `health.hit-flash`, `animation.flash-overlay` | попадание по врагу/герою |
| Волна, молния, след | `$.vfx.shockwave`, `$.vfx.lightning`, `$.vfx.trail`, `animation.afterimage` | рывок, взрыв, магия |
| Всё сразу в точке удара | `$.vfx.impact(x, y, { sound: 'имя' })`, `$.hitFx` | удар по врагу, пуля в стену |
| Частицы | `$('<particles>', $.particles.preset('sparks'))`; пресеты: `explosion`, `smoke`, `sparks`, `fire`, `rain`, `dust` | искры, пыль при посадке, дым, огонь |
| Сгенерировать звук удара/подбора | навык `generate-sound` → `generate_sound`, затем `$.sound.play(путь)` |
| Звук удара | `$.hits.preset('sword', { hitStop: 60, sound: 'sfx/sword.wav' })` + `$.sfx.play('sword')` | любой удар |
| Числа урона, комбо | `health.damage-number`, `feedback.combo-popup`, `feedback.screen-pulse` | подтверждение силы удара |
| Сжатие/растяжение | `$.hits.squash` | прыжок, посадка |

Если не уверен в сигнатуре — `api_lookup` с точным именем.

## 2. Шкала силы

Подбирай эффект под значимость события, не лепи максимум всюду:

| Событие | Эффект |
|---|---|
| подбор монеты | короткий звук, лёгкая вспышка/всплывающее число |
| попадание по врагу | вспышка врага + звук + искры |
| урон герою | тряска + красный пульс экрана (`feedback.screen-pulse`) + неуязвимость с миганием (`health.invulnerability`) |
| смерть врага | частицы + hit-stop + звук |
| смерть босса | замедление, большая тряска, взрыв, затем пауза перед экраном победы |
| прыжок/посадка | пыль (`dust`), сжатие; без тряски |

## 3. Типичные ошибки

* **Слишком много тряски** — глаза устают; тряска только на значимое, затухание за 0.2–0.4 с.
* **hit-stop на каждый удар** — игра «тормозит»; только на сильные, ≤ 100 мс.
* **Эффект без цели:** вспышка на то, что игрок не контролирует. Эффект должен отвечать на действие игрока.
* **Не уважать доступность:** для тряски и вспышек есть `accessibility.reduce-motion` — включи, если игра с интенсивными эффектами.
* Частицы создавай в пуле (повторное использование `$.hitFx`), а не по новому узлу на каждый кадр.

Проверка: `screenshot_check` после события не показывает эффекты в момент (кадр статичен) — убедись по `playtest` с `eval` числа
частиц/состояния и по логике вызова; не гадай, что «выглядит хорошо».

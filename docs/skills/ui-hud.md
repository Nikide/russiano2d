# Навык: HUD, меню и экраны

Правило движка (`docs/UI_RMLUI_LAW.md`): **меню, экраны и диалоги — RmlUi-документы** (`$.ui.doc('ui/x.rml')`). Узлы `<ui.*>`
остаются быстрым способом нарисовать простой HUD (счёт, полоса здоровья), но новые меню на них не строят.

## 1. Что нужно любой игре

| Элемент | Как |
|---|---|
| Здоровье | кирпичик `ui.health-bar` (+ `ui.shield-bar`, `ui.stamina-bar`) или `<ui.bar>` + `$.ui.bind('#hp_bar', () => hero.hp / hero.hpMax)` |
| Счёт, таймер | `<ui.label>` + `label.text(...)` или `$.ui.bind('#score', () => score, { text: (v) => 'Счёт: ' + v })` |
| Подсказка действия | `ui.interaction-prompt` |
| Пауза | `ui.pause-menu` (+ `ui.confirm-dialog`) |
| Настройки | `ui.settings-menu`, `settings.audio`, `settings.controls`, `settings.video` |
| Конец уровня | `ui.result-screen`, выбор уровня — `ui.stage-select` |
| Задания, журнал | `ui.quest-tracker`, `ui.quest-journal` |
| Инвентарь и экипировка | `ui.inventory-screen`, `ui.equipment-screen`, `ui.quickbar` |
| Диалог | `ui.dialogue-box`, `ui.choice-list` |
| Миникарта, карта мира | `ui.minimap-markers`, `ui.world-map` |

Сначала ищи кирпичик (`snippet_find "меню"`); свой RML — только если подходящего нет.

## 2. Свой RmlUi-документ

```js
const menu = $.ui.doc('ui/menu.rml');          // файл ui/menu.rml в проекте
menu.show();                                    // doc.hide() — скрыть
menu.on('click', '#start', () => $.scene.load('level'));
```

Правила разметки (иначе документ ломается молча):

* **`{{` и `}}` в тексте нельзя** — RmlUi принимает их за привязку данных. Пиши с пробелом между скобками или другим текстом.
* Картинка из спрайтшита в `.rcss`: `@spritesheet` + `decorator: image(имя)`; голое `decorator: имя` не работает.
* Класс меняют так: `doc.attr('id', 'class', 'active')`. Прокрутка списка: `doc.scroll(...)`.
* Все id документов — латиница; id должны быть уникальны в документе.
* Шрифты, цвета и отступы держи в одном `.rcss`, не в десяти `style=` — меню остаётся единым.

## 3. Раскладка и читаемость

* HUD по краям: здоровье — слева сверху, счёт — справа сверху, подсказки — снизу по центру. Центр экрана — только игра.
* Не больше 4–5 постоянных элементов. Остальное — по событию (всплывашка `feedback.quest-toast` и скрытие через 2–3 с).
* Текст — крупнее 18 px, контраст с фоном. Для масштаба интерфейса есть `$.ui.scale()`.
* Координаты узлов `$.ui` — окна, а не мира: они не двигаются с камерой.
* Кнопки и состояния: у каждой кнопки есть hover и фокус (геймпад: `$.ui.gamepadNavigation`).

## 4. Рабочий цикл

1. HUD минимального набора (здоровье + цель) сразу после первого играбельного кадра.
2. Пауза/победа/поражение — до полировки.
3. `screenshot_check grid:true` — элементы на своих местах, не перекрывают игру.

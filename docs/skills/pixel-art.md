# Навык: пиксель-арт

Как нарисовать спрайт, тайл или анимацию самому, не имея картинки. Инструмент — `pixel_art` (в CLI: `r2d pixel-art <spec.json>`):
спецификация описывает холст, палитру и пиксели **текстом**, результат — PNG в проекте плюс **ASCII-срез**: по нему видно, что
получилось, даже если у модели нет зрения. Рабочий цикл: нарисовал → прочитал срез → поправил `ops` → интегрировал в игру.

## 1. Размеры и стиль

| Что | Размер | Заметки |
|---|---|---|
| тайл, предмет, монета, пуля | 8×8, 16×16 | тайл рисуй так, чтобы края стыковались |
| маленький персонаж, враг | 12×16 … 16×24 | одна тёмная обводка в 1 пиксель |
| главный герой | 24×24 … 32×32 | больше места для лица и деталей |

Правила, которые дают «читаемый» результат:

* **Палитра 4–10 цветов.** Для каждого материала — тёмный, базовый, светлый тон. Не бери чисто чёрный для обводки — возьми
  самый тёмный оттенок палитры (например `#1a1020`).
* **Свет сверху-слева.** Светлые пиксели — сверху и слева, тень — снизу и справа.
* **Силуэт важнее деталей.** Сначала крупные формы (`rect`, `ellipse`, `rows`), потом глаза, пояс, блики.
* **Симметрия:** нарисуй левую половину `rows`, затем `{"op":"mirror"}` достроит правую.
* **Обводка:** `{"op":"outline","c":"k"}` обводит непрозрачные пиксели; цвет обводки держи в палитре, иначе в ASCII-срезе
  он сольётся с ближайшим цветом палитры.
* Прозрачность — символ `.` (его не нужно объявлять в палитре).

Готовые палитры (подставляй в `palette` под своими буквами):

* **DB16:** `#140c1c #442434 #30346d #4e4a4e #854c30 #346524 #d04648 #757161 #597dce #d27d2c #8595a1 #6daa2c #d2aa99 #6dc2ca #dad45e #deeed6`
* **PICO-8:** `#000000 #1d2b53 #7e2553 #008751 #ab5236 #5f574f #c2c3c7 #fff1e8 #ff004d #ffa300 #ffec27 #00e436 #29adff #83769c #ff77a8 #ffccaa`

## 2. Спецификация

| Поле | Смысл |
|---|---|
| `out` | куда записать PNG, например `assets/hero.png` (папки создаются) |
| `palette` | `{"k":"#1a1020", "g":"#3fae5a"}` — ключ один символ; `null` — прозрачный |
| `rows` | строки-пиксели `["..kk..", ...]`: символ палитры красит пиксель, остальное не трогает |
| `frames` | кадры анимации `[{"rows":[...]}, ...]` — ложатся в ряд, получается лист |
| `size` | `[w, h]` пустого холста, если нет `rows` (рисуешь одними `ops`) |
| `base` | существующий PNG для правки (`ops` поверх него) |
| `ops` | операции по порядку (ниже) |
| `scale` | целое 1…16: увеличить итоговый PNG без сглаживания |
| `preview` | путь второго PNG с крупным увеличением — для показа человеку в чате |

Операции `ops` (цвет `c` — ключ палитры или `#rrggbb`/`#rrggbbaa`, `transparent` стирает):
`set {x,y,c}`, `rect {x,y,w,h,c,fill}`, `line {x0,y0,x1,y1,c}`, `ellipse {cx,cy,rx,ry,c,fill}`, `fill {x,y,c}` (заливка по цвету),
`replace {from,to}`, `flip {axis:"h"|"v"}`, `mirror {axis}`, `shift {dx,dy}`, `outline {c}`, `clear`.

## 3. Примеры (рабочие: проверяются тестом)

Монета 8×8:

```json
{"palette":{"k":"#442434","y":"#dad45e","o":"#d27d2c","w":"#fff1a0"},
 "rows":["..kkkk..",".kyyyok.","kywyyyok","kywyyyok","kyyyyyok","kyyyyyok",".kyyyok.","..kkkk.."],
 "out":"assets/coin.png"}
```

Герой 12×13 (цветные области + обводка):

```json
{"palette":{"k":"#1a1020","g":"#3fae5a","d":"#2b7a40","s":"#f5c9a0","w":"#ffffff","r":"#d94a4a"},
 "rows":["....kkkk....","...kggggk...","..kggggggk..","..kgsssdgk..","..kswkswsk..","..kssssssk..","...kssrsk...","..kkggggkk..",".kggggggggk.",".kgkggggkgk.","..kk.kk.kk..","..kdk.kdk...","..kkk.kkk..."],
 "ops":[{"op":"outline","c":"k"}],
 "out":"assets/hero.png"}
```

Корабль 11×8: рисуется левая половина (6 колонок с центральной), `mirror` достраивает правую:

```json
{"palette":{"k":"#1a1020","r":"#d04648"},
 "size":[11,8],
 "rows":["....k.","...kk.","..kkk.",".kkrk.","kkkkkk","k.kkkk","k.k...","..kk.."],
 "ops":[{"op":"mirror"}],
 "out":"assets/ship.png"}
```

Тайл травы 16×16 (заливка, шум по точкам):

```json
{"palette":{"g":"#6daa2c","d":"#346524","l":"#a4d84a","b":"#854c30"},
 "size":[16,16],
 "ops":[{"op":"rect","x":0,"y":0,"w":16,"h":16,"c":"g"},{"op":"rect","x":0,"y":12,"w":16,"h":4,"c":"b"},
        {"op":"rect","x":0,"y":10,"w":16,"h":2,"c":"d"},{"op":"set","x":3,"y":4,"c":"l"},{"op":"set","x":9,"y":2,"c":"l"},
        {"op":"set","x":12,"y":7,"c":"d"},{"op":"set","x":5,"y":8,"c":"d"}],
 "out":"assets/grass.png"}
```

Слизень, анимация из двух кадров (лист 24×6, кадр 12×6):

```json
{"palette":{"k":"#1a1020","s":"#6dc2ca","l":"#deeed6","e":"#140c1c"},
 "frames":[{"rows":["............","...kkkkkk...","..kssssssk..",".kssleslesk.",".ksssssssk..",".kkkkkkkkkk."]},
           {"rows":["............","............","..kkkkkkkk..",".kssslesslk.",".ksssssssssk","kkkkkkkkkkkk"]}],
 "out":"assets/slime.png"}
```

## 4. Как подключить в игру

Один спрайт: `$('<sprite>', { id: 'hero' }).sprite('assets/hero.png').at(200, 300).size(48, 52).appendTo($.world)`
(размер задаёт, во сколько раз увеличить: пиксель-арт 12×13 → 48×52 это ×4). Не сглаживай: рисуй сразу `scale` или задавай
целочисленный размер.

Лист анимации (кадры в ряд, `cw`×`ch` — размер одного кадра):
`$('<sprite>').frames({ src: 'assets/slime.png', cols: 2, rows: 1, cw: 12, ch: 6 }).animate({ from: 0, to: 1, speed: 4, loop: true })`.

Для атласа с тегами: `r2d atlas-grid assets/slime.png --out assets/slime.atlas.json --cols 2 --rows 1 --tags idle:0-1`.

## 5. Если получилось не то

Прочитай `ascii` и найди проблему: «плывёт» силуэт (лишние пиксели) → поправь `rows` или сотри `rect` цветом `transparent`;
сливаются тона → разведи палитру; не симметрично → `mirror`; нужно сдвинуть → `shift`. Правь существующий файл через `base` +
`ops` (повторно рисовать всё не нужно). Сомневаешься в размерах — открой результат инструментом `pixel_preview` (в нём ASCII
и крупное превью).

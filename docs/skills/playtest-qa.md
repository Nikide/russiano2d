# Навык: проверка игры и поиск багов

Игра не «готова», пока её не прогнали. Инструменты: `playtest` (ввод + `eval` состояния + ASCII-карта кадра), `screenshot_check`,
`r2d_lint`, `r2d_validate`, `run_check`, `api_lookup`.

## 1. Лестница проверок (от дешёвой к дорогой)

1. `r2d_lint` — неверный `$`-API, опечатки (после каждой записи `.js` линт уже запущен — исправь замечания).
2. `r2d_validate` — структура проекта, ассеты, `project.json`.
3. `screenshot_check` — кадр не пустой? `КАДР ПУСТОЙ` = игра не работает: ищи ошибку, а не поправляй цвета.
4. `playtest` — поведение: ввод, состояние, цель.
5. `run_check` — прогон тестов проекта.

## 2. Рецепты `playtest`

| Что проверить | Сценарий |
|---|---|
| Герой двигается | `hold ["D"], frames 60` → `eval JSON.stringify($('#hero').pos())`, позиция изменилась |
| Прыжок | `tap "Space"`, `frames 15` → y меньше исходного |
| Границы мира | `hold ["D"], frames 600` → x не больше правой границы |
| Подбор предметов | поставь героя на предмет → `eval` счёта/числа предметов |
| Урон | поставь героя у врага/шипа, `frames 60` → здоровье уменьшилось |
| Смерть и респаун | доведи здоровье до нуля → герой на чекпоинте, здоровье восстановлено |
| Победа | дойти до выхода → показан экран результата |
| Экран | `grid: true` → ASCII-карта: что где нарисовано |

`eval` выполняется в игре: читай конкретные поля (`$('#hero').pos()`, `$('text').text()`), а не «всё состояние».
Между шагами прокручивай `frames` — без них физика не успевает.

## 3. Поиск причины: по симптомам

| Симптом | Куда смотреть |
|---|---|
| Чёрный экран | ошибка в `main.js` (`r2d_lint`), нет `appendTo($.world)`, камера смотрит мимо, не выбрана сцена |
| Герой не двигается | не подключено движение (`snippet_apply`), не тот `id` в `owner`, объект не `<player>` |
| Герой проваливается | пол — `<sprite>` вместо `<wall>`, нет `collision` |
| Герой улетает | нет `$.world.bounds(...)` |
| Объект не реагирует на кирпичик | нестатический `id` (в цикле из строки), `owner` указан неверно |
| Текст не обновляется | текст обновляют `label.text("…")`, а не пересозданием |
| Эффекта нет | вызов до готовности (`$.ready`), неверное имя (проверь `api_lookup`) |
| `R2D00x`-диагностика | прочитай `r2d_lint` — там точное место и подсказка |

## 4. Дисциплина

* Нашёл баг — воспроизведи `playtest`-ом **до** правки, исправь, повтори тот же сценарий **после**.
* Исправляй причину. Если правка не помогла дважды — открой код заново (`read_file`), а не наращивай заплатки.
* Не повторяй проверку без правок — результат тот же.
* В отчёте пользователю — что проверено и чем (сценарий + результат), а не «должно работать».
* Если чего-то не проверить (звук, плавность) — скажи прямо.

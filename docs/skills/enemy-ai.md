# Навык: враги и ИИ

Поведения врагов — кирпичики `ai.*`. Пиши ИИ кодом только если ни один кирпичик не подходит.

## 1. Выбор поведения

| Что должен делать враг | Кирпичик |
|---|---|
| Стоит, пока не заметит | `ai.idle`, `ai.guard-post`, `ai.line-of-sight` (видит ли цель), `ai.hearing` |
| Ходит по маршруту | `ai.waypoint-patrol` |
| Бежит за целью | `ai.chase`, `ai.follow-target`, возврат при потере — `ai.leash` |
| Бьёт вблизи | `ai.melee-attack` |
| Стреляет издалека | `ai.ranged-attack`, `ai.cover` (прячется за укрытием) |
| Заходит с фланга, строем | `ai.flank`, `ai.formation` |
| Убегает при низком здоровье | `ai.flee` |
| Ищет после потери из виду | `ai.investigate`, `ai.search` |
| Появляется волнами | `ai.spawner`, `ai.wave-director` |
| Босс | `ai.boss-phases` (смена фаз по здоровью), `ai.boss-telegraph` (предупреждение перед ударом) |

Стелс собирается набором `kit.stealth`; оборона — `kit.horde-defense`, `kit.tower-defense`.

## 2. Как сделать врага интересным

* **Читаемость важнее сложности.** Перед сильной атакой — видимое предупреждение (`ai.boss-telegraph`, вспышка, звук). Игрок должен
  понимать, за что получил урон.
* **Каждый новый тип врага меняет решение игрока:** быстрый слабый, медленный сильный, дальний, летающий. Три разных типа лучше десяти похожих.
* **Роли в комнате:** один «танк», пара стрелков, один быстрый — враги дополняют друг друга.
* **Дай окно возможности:** после атаки враг на 0.5–1 с уязвим (`health.stagger`).
* **Урон обратной связи:** вспышка (`health.hit-flash`), отбрасывание (`health.knockback-reaction`), смерть (`health.death`) + награда (`economy.loot-table`).
* Здоровье врагов — `health.base` с маленьким числом: убийство за 1–3 попадания в начале игры.

## 3. Параметры, которые чаще всего неудачны

| Проблема | Причина | Лекарство |
|---|---|---|
| Враг сразу убивает героя | высокий урон, нет неуязвимости | `health.invulnerability` 0.6–1 с после удара |
| Враг «сквозь стены» | нет `collision` | объект — `<player>`-подобный вид с физикой или `<wall>`-запрет |
| Враг не замечает героя | радиус обнаружения меньше экрана | радиус ≥ половины экрана для стражей |
| Бесконечная погоня | нет `ai.leash` | предел расстояния возврата |
| Волна «стена врагов» | все появились разом | задержки между появлениями в `ai.wave-director` |

## 4. Проверка

`playtest`: поставить героя рядом с врагом, прокрутить 60–120 кадров, `eval` здоровья героя/врага — убедиться, что враг реагирует.
Затем герой вне радиуса — враг не реагирует (нет ложных срабатываний).

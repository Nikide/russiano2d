# Visual Novel Maker (SDK)

Визуальный редактор **существующего** narrative runtime: `.scene` → Narrative IR
→ `$.story` → `$.dialog` → RmlUi. Второго интерпретатора и второго формата нет.

## Открыть

SDK → **ГОТОВЫЕ РЕШЕНИЯ** → **Visual Novel Maker** (id `vn-narrative`).
Файл инструмента: `sdk/tools/vn-narrative.js`, контроллер:
`sdk/lib/vn_maker.js`, UI: `sdk/ui/vn_maker.rml` + `.rcss`.

## Что редактирует

- `story/*.scene` — исходный текст, один файл = одна сцена;
- `story/speakers.json` — список персонажей и JSON-редактор реестра
  (`speakers` → записи с `expressions`);
- темы/ассеты — через существующие RmlUi Studio/Asset Browser.

## Основной экран

- слева: сцены, метки, персонажи (список + форма), поиск по всему проекту;
- в центре: вертикальный список команд (SAY / CHOICE / LABEL / GOTO / IMAGE /
  SOUND / CUSTOM), кнопки добавления/удаления/перемещения/дубля;
- справа: инспектор команды, выбор ассетов, тема/i18n-сводка и диагностика;
- **Source** — прямое редактирование `.scene`; структурированный список и
  источник синхронизируются из одного текста.

Команды, которые редактор не понимает, показываются как `CUSTOM` и
сохраняются как есть. Пустые строки и комментарии не теряются. Undo/Redo
работают по операциям над сценой (правки инспектора, вставка, удаление,
перемещение, дубль).

## Предпросмотр

`Play` проигрывает текущий текст через настоящий `$.story.play({text})`,
`Play From Here` — с выбранной строки, `Stop` — `$.story.stop()`.
Это runtime, а не отдельный рендерер; при остановке story снимает свои
блокировки/аудио штатным поведением.

«Play From Here» восстанавливает то, что можно: `set`-флаги, актёров, камеру,
изображения и звук из префикса; диалоги/выборы/переходы в префиксе пропускаются,
поэтому выборы до выбранной строки не применяются.

## Проверка

Кнопка **Проверить** вызывает `r2d-sdk story validate <каталог сцены>` через
SDK backend. Диагностика показывается справа; GUI не «исправляет» сюжет
молча.

## Горячие клавиши

- Cmd/Ctrl+S — сохранить;
- Cmd/Ctrl+Z — undo, Cmd/Ctrl+Shift+Z — redo;
- Cmd/Ctrl+F — поиск.

## Agent operations

Панель регистрируется как `app.studios['vn-maker']` и отдаёт снимок
`{active, scene, dirty, selectedCommand, commandCount, previewRunning,
previewIndex, validation}`. Методы:

```js
openScene(path)  newScene(path)  save()  validate()
select(index)  insert(kind)  update()  delete()  move(delta)  duplicate()
listScenes()  listLabels()  search(query)
playScene()  playFromHere()  stopPreview()
listSpeakers()
```

Кнопки UI вызывают те же методы — отдельной «агентской» логики нет.

## Ограничения текущего этапа

- портреты выражений пока задаются путями/JSON-реестром, без отдельной галереи;
- выбор ассетов из Asset Browser ещё не подключён;
- предпросмотр не реконструирует состояние мира до произвольной строки;
- граф-вью как опциональный обзор меток не реализован.

## Модель исходного текста

`sdk/lib/vn_model.js` содержит операции авторинга над строками `.scene/.story`,
без исполнения команд. Она сохраняет CRLF/LF, комментарии, неизвестные строки
и отсутствие перевода строки в конце файла. Правка выбора сохраняет `{flag…}`;
правка пути изображения сохраняет длительность. Поведение проверяется
`tests/js/vn_model_test.mjs` (7 тестов). Исполнение остаётся в `$.story`,
семантическая проверка — в native `r2d story validate`.

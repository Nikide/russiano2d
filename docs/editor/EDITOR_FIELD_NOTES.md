## EFN-001 — Run стартовал до завершения сохранений

- **Дата:** 2026-10-20.
- **Проект:** временный тестовый проект; две Input Studio вкладки и JS файл.
- **Цель и шаги:** изменить ресурс в студии, затем нажать Run.
- **Ожидалось:** Run дожидается Save All для кода и native-студий; при неудаче
  запись остаётся dirty и игра не запускается.
- **Фактическое до исправления:** `run()` вызывал `save()` без `await` только для
  JS документов, а dirty-ресурсы не сохранялись.
- **Поверхность/влияние:** Run/Stop и документ ресурса; мог запускаться устаревший
  проект. Обход — вручную Save All перед каждым запуском.
- **Причина:** отдельная ветка сохранения внутри `run()` обходила общий контракт.
- **Критерий исправления:** `run()` ожидает `saveAll()` и не запускает процесс,
  если сохранение вернуло ошибку.
- **Статус:** Run/Save All исправление headless-проверено через
  `tests/agent/editor_save_test.py`; явные действия dirty close дополнительно
  закрыты и записаны в EFN-019.

## EFN-002 — вложенный путь Xmake не находил Editor

- **Дата:** 2026-10-20.
- **Проект:** репозиторий Russiano2D, macOS arm64.
- **Цель и шаги:** запустить `build-xmake/macos-arm64/macosx/arm64/release/r2d`
  без аргументов.
- **Ожидалось:** единый бинарник находит `editor/` в checkout и открывает
  Project Manager.
- **Фактическое до исправления:** поиск поднимался только на 4 каталога, а
  checkout расположен глубже.
- **Поверхность/влияние:** запуск Editor из dev-сборки; GUI обход — запускать
  бинарник из каталога с более мелким путём либо использовать пакет.
- **Причина:** поиск учитывал старое расположение `build/r2d`, но не вложенную
  иерархию Xmake.
- **Критерий исправления:** поиск доходит до корня checkout, не требуя второго
  бинарника или изменения структуры `dist/`.
- **Статус:** исправлен предел обхода в `src/main.c`; после Xmake build процесс
  успешно загрузил `editor/main.js`. Само окно не отображалось в UI-инвентаре,
  поэтому визуальное состояние Project Manager не подтверждено.

# Демо: эталонное меню настроек

Ответ на вопрос «можно ли на нашем движке сделать полноценное меню настроек» —
рабочий образец: четыре вкладки, всё применяется **на лету**, сохраняется в
`settings.json` и переживает перезапуск движка.

```bash
./build/russiano2d --game demos --scene settings
```

Внутри демо (и в меню-лаунчере есть карточка «Настройки»):

| Вкладка | Что настраивается |
|---|---|
| **Графика** | полный экран (`windowed`/`desktop`/`exclusive`), разрешение из `$.window.displayModes()`, масштаб интерфейса `$.ui.scale()`, сглаживание `$.gfx.smaa()`, показ FPS |
| **Звук** | общая громкость, эффекты, музыка, тишина, кнопка «проверить звук», строка состояния с `$.sound.busy()` и `channels()` |
| **Управление** | переназначение клавиш с захватом следующего нажатия (`$.input.waitForInput`), сброс к эталону (`$.input.resetDefaults`), навигация геймпадом |
| **Язык** | переключение `$.i18n` на лету (подписи этого же меню перерисовываются), сброс всех настроек |

## Управление

| Ввод | Что делает |
|---|---|
| `↑` `↓` / стик или d-pad | кольцо выбора по строкам |
| `←` `→` | значение выбранной строки (ползунок, список, флажок) |
| `Enter` / `A` | изменить: переключить, начать захват клавиши, выполнить действие |
| `Esc` / `B` | отменить захват; выйти из меню |
| мышь | клик по строке: первый — выбор, повторный — действие; наведение двигает кольцо |
| `Tab` | следующая вкладка |

## Из чего состоит

| Файл | Что это | Строк |
|---|---|---|
| `settings.rml` | разметка RmlUi: вкладки, строки, ползунки, подсказки | 170 (155 кода) |
| `settings.rcss` | стили: адаптивные размеры в `vh`, кольцо выбора, состояния | 190 (146 кода) |
| `index.js` | логика: настройки, применение, сохранение, ввод, геймпад | 757 (620 кода, ещё ~96 — словари ru/en) |

Интерфейс — документ RmlUi, а не узлы `<ui.*>`: так требует
[закон интерфейса](../../docs/UI_RMLUI_LAW.md). Кольцо выбора ведёт JS: геймпад
превращается в действия меню, потому что `$.ui.gamepadNavigation` работает со
слоем `$`-виджетов и документы RmlUi этим путём не ходят
([input.md §15](../../docs/highlevel/input.md)).

Настройки лежат в `settings.json` (файл игрока, в репозиторий не едет) —
отдельно от `save.json` игры, чтобы сброс настроек не трогал прохождение.

## Числа

Замер на живой сборке (`macos-arm64`, headless, фиксированный шаг 1/60):

* **открытие экрана** — 10.5 мс (загрузка документа + применение всех настроек);
  повторное `hide()`/`show()` уже загруженного документа — 23 мкс;
* **кадр**: зона «интерфейс (RmlUi)» 0.080 мс с открытым меню против 0.023 мс с
  закрытым, то есть меню стоит **≈ 0.06 мс на кадр** (0.35 % бюджета 16.7 мс при 60 FPS);
* **применение настройки**: полный экран 1.76 мс, смена языка 0.28 мс,
  разрешение 50 мкс, SMAA 30 мкс, громкости 1–7 мкс, масштаб 3 мкс;
  сброс всех настроек — 0.61 мс вместе с записью файла;
* **файл настроек** — 718 Б на все 15 значений, запись 0.36 мс.

Подробный разбор с кодом — [docs/tutorial-settings.md](../../docs/tutorial-settings.md).
Проверяется автотестом `tests/agent/settings_menu_test.py`.

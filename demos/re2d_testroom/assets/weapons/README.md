# Maid FPS Weapons — спрайты и синтезированные звуки

Три оружия от первого лица в руках девушки с тёмными рукавами и белыми манжетами: pistol, shotgun, ak.

## Что находится в архиве

- sprites/<оружие>/atlas.png — PNG RGBA, 384×256, сетка 3×2, ячейка 128×128.
- sprites/<оружие>/00…05_*.png — шесть отдельных кадров 128×128 с прозрачностью.
- sources/ — исходные изображения высокого разрешения, созданные imagegen.
- audio/<оружие>/ — синтезированные WAV, моно PCM 16-bit, 44100 Hz.
- previews/ — GIF-проверки стрельбы и перезарядки на однотонном фоне. Фон есть только в GIF.
- animations.json — прямоугольники кадров, рекомендуемые тайминги, пути звуков.

## Порядок кадров

Индексы начинаются с нуля. Верхний ряд: 0 — покой, 1 — малая вспышка, 2 — выстрел/пиковая отдача.
Нижний ряд: 3 — возврат после отдачи, 4 — переход перезарядки, 5 — возврат в готовность.
У дробовика кадры 3 и 4 передают цикл цевья. Его удачный исходный рисунок сохранён.

## Как подключить

Фильтрация nearest / point. Не обрезать прозрачные поля отдельно у каждого кадра.
Опорная точка всех ячеек — центр нижней границы: (64, 128) в координатах границы изображения.
Рисовать HUD после мира. Использовать обычное straight-alpha смешивание SRC_ALPHA / ONE_MINUS_SRC_ALPHA.
Для чёткого ретро-вида масштабировать в целое число раз. Прозрачность читать из alpha, а не по чёрному цвету RGB.

Стрельба: 0 → 1 → 2 → 3 → 0. Выстрел воспроизводить один раз при входе в кадр 1, случайно выбирая fire_01…03.wav.
У АК каждый новый выстрел запускает короткий цикл заново; не использовать WAV как бесшовный цикл.
Тайминги в animations.json — стартовые настройки, а не проверенный в вашем движке баланс.

## Перезарядка

Пистолет и АК используют упрощённую игровую перезарядку с опусканием оружия:
искажённые крупные планы вставки магазина заменены переходным кадром.
Для плавного варианта перемещать кадр 4 вниз за экран за 150 мс, удерживать скрытым 650 мс,
затем поднимать кадр 5 за 200 мс и возвращать кадр 0. Это движение делает движок;
оно не запечено в отдельные промежуточные PNG. GIF показывает только имеющиеся позы.
Не считать этот набор подробной покадровой анимацией смены магазина.

У дробовика reload.wav — звук передёргивания цевья после выстрела, не полная дозарядка магазина.
Для игровой дозарядки есть отдельный shell_insert.wav; кадров вставки патронов нет.

## Звуки

fire_01.wav…fire_03.wav — три варианта одиночного выстрела.
reload.wav — цельный стилизованный звук перезарядки/цикла цевья.
mechanism.wav — отдельный короткий механический звук для событий анимации.
shotgun/shell_insert.wav — дополнительный щелчок дозарядки.
Все звуки созданы процедурным синтезом, без записей реального оружия и без сэмплов Doom.
Выстрелы намеренно ретро-стилизованы. Пиковый уровень ограничен примерно −1,7 dBFS;
при одновременном воспроизведении нескольких источников оставить запас громкости в микшере.

## Статус и происхождение

Файлы подготовлены для импорта: точные размеры, общий canvas, alpha, именование и JSON.
Это PNG/WAV-пакет, не WAD/PK3 и не готовый мод. В конкретном движке не тестировался.
Генерация может давать небольшие изменения формы между кадрами; художественная стабильность не гарантируется.
Исходники созданы встроенным imagegen по предоставленным пользователем референсам;
оригинальный SNES/Doom-атлас и портрет не включены в архив.

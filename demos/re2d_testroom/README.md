# Демо «Re2D · тестовая комната врагов на билбордах»

Комната 1600×1200 с внутренними стенами. Игрок **ходит** от первого лица
(WASD + мышь), а враги — **плоские PNG-билборды**: картинка стоит на полу,
всегда повёрнута к камере, патрулирует комнату, замечает игрока и подходит.
**Оружия, стрельбы, урона и боя в комнате нет** — только прогулки.

```bash
./build/russiano2d --game demos --scene re2d_testroom
./build/russiano2d --game demos        # кнопка «Re2D · комната врагов»
```

| Управление | Что делает |
|---|---|
| `W` `A` `S` `D` | ходить: вперёд — куда смотрит камера, `A`/`D` — боком |
| мышь | смотреть (курсор захвачен), `Esc` — назад в меню |
| — | оружия нет: ни `.re2dSprite.equip`, ни `$.weapons` |

## 1. Что проверяет

| Слой | Чем сделан |
|---|---|
| вид от первого лица | `$.camera.kind(Re2D).eye(52).fov(72).mouseLook(...)`; `$.camera.follow('#hero', {smooth: 0})` — жёсткое следование |
| комната | `$.re2d.room({...})` + две внутренние `<wall>` с `.body('static').kind(Re2D)` |
| игрок | обычный `<player>` с `.controls('wasd')` и `.kind(Re2D)` (динамическое тело Box2D) |
| враги | `<enemy>` + `.sprite(png)` + `.size(120, 237)` + `.body('kinematic').kind(Re2D)` |
| ходьба врагов | JS-патруль по точкам маршрута; кинематическое тело, поэтому игрок об врага упирается |
| реакция | ближе 380 px — «заметил» и идёт к игроку, но останавливается за 130 px; атак нет |
| интерфейс | обычные `ui`-узлы поверх 3D: заголовок, подсказка, прицел, статус |
| агент | `$.agent.expose('re2dTestroom', …)`: игрок, камера, враги, `weapons: 0` |

## 2. Что полируется этим демо

1. **Плоский PNG как билборд** работает без `character.json`/атласа v2: узел
   `<enemy>` с `.sprite(png)`, `.size(w,h)`, `.depth(0)` и `.kind(Re2D)`
   рисуется на полу и всегда разворачивается к камере.
2. **Кинематический билборд-враг**: ходит по маршруту (`.at()` двигает и тело),
   при этом не продавливается игроком и сам его останавливает.
3. **Камера FPS без сглаживания**: `smooth: 0` — глаза не отстают от тела.
   (До этой правки у камеры было 0.12 «догоняния», в FPS это читается как
   «плывущие глаза».)
4. **Единицы yaw**: `$.camera.yaw()` — ГРАДУСЫ. В первой версии демо стояло
   `-Math.PI/2`, и игрок при `W` шёл не вперёд, а почти на восток
   (x 800 → 973 при y 1080 → 1075). Нашлось замером ходьбы; исправлено на `-90`.
5. **HUD над 3D**: RmlUi не обязателен — обычные `ui`-узлы рисуются поверх
   Re2D-кадра.
6. **Луч видимости перед погоней**: кинематический враг не умеет обходить
   стены, поэтому «заметил» проверяется 2D-лучом `$.world.raycast` по телам
   комнаты. За внутренней стеной враг остаётся на патруле и не идёт напролом.

## 3. Проверка без рук

```bash
python3 tests/agent/re2d_testroom_test.py
```

Тест проверяет: ходьбу вперёд (`y 1080 → 906.7`), упор в стену (`y = 633`),
ходьбу назад (`y = 1185`), боковое движение, жёсткую камеру
(`camera == hero`), патруль врагов, луч видимости (за стеной `seen=false`,
враг не идёт), «замечание» игрока в открытую, отсутствие оружия
(`weapons: 0`, ноль узлов `weapon`/`bullet`) и видимость билборда по скриншоту
(зелёные пиксели арта > порога; спрятанный враг убирает свой арт).

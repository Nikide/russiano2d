# Платформер «Тропа к звезде»

Небольшой 2D-уровень, который создан через Russiano2D Editor: тайловая карта и слой коллизий отредактированы в Tilemap Studio, игровой код вынесен в отдельный `game.js`. Персонаж — спрайт-лист маскота из существующих ресурсов проекта.

## Запуск

Откройте папку проекта в Editor и нажмите «Запустить». Цель — пройти пять платформ и коснуться звёздного флага. После победы нажмите `R`, чтобы начать заново.

## Управление

- `A` / `D` или `←` / `→` — идти.
- `Space`, `W` или `↑` — прыгать.
- `R` — перезапустить уровень.

## Структура

- `main.js` только импортирует `game.js`.
- `game.js` содержит игровую логику на `$`: ввод, физику, анимацию маскота, камеру и условие финиша.
- `level.tilemap.json` создан командой Editor и настроен в Tilemap Studio.
- `assets/tiles/platformer_tileset.png` и `assets/mascot/rusiano_walk_sheet.png` — повторно использованные ассеты движка.

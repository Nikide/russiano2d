# assets для real2d

Сюда кладутся ассеты демо Re2DSprite v4 — они лежат рядом с точкой входа, чтобы
`--game demos/real2d` находил их первым (порядок разрешения путей —
[docs/BUILD.md](../../../docs/BUILD.md)).

Ожидаемые имена (как у v2/v3, см. [demos/rotsprite](../rotsprite/README.md)):

| Файл | Что внутри |
|---|---|
| `<имя>.png` | развёртка персонажа или оружия |
| `<имя>.character.json` | описание материала и развёртки |
| `<имя>.animations.json` | клипы движения |
| `<имя>.bake.json` | отчёт бейкера (что и как запечено) |

Пока папка пуста: ассеты v4 появятся вместе с реализацией. Готовые модели для
проверки каркаса берутся из соседнего демо — `demos/rotsprite/` и
`demos/re2d_gun_viewer/`; дублировать их сюда не нужно.

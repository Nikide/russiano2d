# Re2DSprite Lab

`./build/russiano2d --game demos --scene re2dsprite`

PNG 4096×4096 содержит материалы всего персонажа, лицо и служебные карты.
Демо использует `.re2dStyle('anime')`: чистые cel-материалы, сглаженная
проекция 256×256, плавные позиции и масштаб. Спецификация: `docs/RE2DSPRITE_V2.md`. Это экспериментальный генератор
спрайтов в обычном 2D-батче. Готовых ракурсов и кадров ходьбы нет.

Кнопки переключают голову/тело, волосы, движение и лицо.
Стрелки — yaw/pitch; пробел — автоповорот; Q/W — независимый поворот головы;
G — без предмета/АК-47/пистолет/дробовик; L — стойка/ходьба/бег; H — волосы;
V — эмоция; E — глаза; M — рот; B — моргание; T — речь;
R — перечитать JSON/PNG; Esc — меню. Кисти можно перетаскивать мышью.
Локомоция — цикл на месте; общего IK и физики одежды нет.

Атлас для разработчика: `assets/rotsprite/rotsprite_v2_template.png`.
Маскот и доноры: `demos/assets/art/mascot/russi_rotsprite_*.png`.
Авторские исходники: `source/`, запросы imagegen: `source/PROMPTS.md`.
Пересборка всех PNG: `python3 tools/make_rotsprite_v2.py` (Pillow).

Автоматическое обновление сохраняет позу, мимику, костюм и цикл движения.
Ошибка обновления оставляет последний действующий персонаж.
Левый обзор — обычный кеш текстуры R2D; перезапустить сцену для его обновления.
Старый формат v1 и генераторы сохранены для совместимости.

Голова теперь имеет профиль носа/губ/подбородка в картах PNG, детали лица
скрываются на дальней стороне. Торс и конечности имеют разные объёмы
по высоте и спереди/сзади. Профиль проверяется тем же PNG при yaw=±90.

Материалы горничной используют непрерывную развёртку; волосы и банты
обновлены. Исходники и запросы: `source/POLISH_PROMPTS.md`.

Модель и анимации: russi.character.json, russi.animations.json.
Сборка JSON-атласов: tools/build_rotsprite_assets.py demos/rotsprite/build.json
и demos/rotsprite/weapons/build.json. Формат: docs/RE2DSPRITE_JSON.md.
Шаблоны других моделей: templates/. Оружие: weapons/, отдельные PNG и сокеты.
Крепления проверяются при yaw/pitch и JSON-локомоции. Поза второй руки
задана клипом, общего IK нет; межмодельное перекрытие пока приближённое.

Полное руководство разработчика/художника: `docs/RE2DSPRITE_GUIDE.md`.

Смена костюмов убрана из демо: используется базовый атлас модели.
API подмены частей и исходные PNG остаются доступными.

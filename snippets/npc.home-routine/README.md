# Дом — работа — отдых

Распорядок дня между тремя точками по игровым часам.

Поля:

- `home` (vec2) — Дом
- `work` (vec2) — Работа
- `rest` (vec2) — Отдых
- `workFrom` (int) — Работа с
- `workTo` (int) — Работа до
- `sleepFrom` (int) — Сон с
- `dayLength` (number) — Длина суток
- `speed` (number) — Скорость

# Снайперская винтовка

Прицеливание с приближением камеры и выстрел, пробивающий несколько целей.

Поля:

- `aimKey` (string) — Прицел
- `key` (string) — Выстрел
- `damage` (number) — Урон
- `range` (number) — Дальность
- `pierce` (int) — Пробивает целей
- `zoom` (number) — Приближение
- `cooldown` (int) — Перезарядка
- `targets` (string) — Цели

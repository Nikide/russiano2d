# Задание

Описание задания $.quest: название, выдающий, цели «текст=число», награда, после каких заданий.

Поля:

- `id` (string) — ID
- `title` (string) — Название
- `giver` (string) — Выдающий
- `objectives` (list) — Цели (текст=число)
- `after` (list) — После заданий
- `money` (int) — Награда: деньги
- `items` (list) — Награда: предметы (id=число)
- `autoAccept` (bool) — Взять сразу

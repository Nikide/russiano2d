# Мина

Установка мины: взводится через задержку, взрывается при приближении цели.

Поля:

- `key` (string) — Клавиша
- `arm` (int) — Взведение
- `trigger` (number) — Радиус срабатывания
- `radius` (number) — Радиус взрыва
- `damage` (number) — Урон
- `targets` (string) — Цели
- `max` (int) — Мин одновременно

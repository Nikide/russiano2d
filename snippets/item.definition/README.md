# Описание предмета

Регистрирует тип предмета в $.items: имя, вид, размер, вес, цена, стопка, иконка.

Поля:

- `id` (string) — ID
- `title` (string) — Название
- `kind` (enum) — Вид
- `size` (vec2) — Размер в клетках
- `mass` (number) — Вес
- `value` (int) — Цена
- `stack` (int) — Стопка
- `heal` (int) — Лечение
- `icon` (asset) — Иконка

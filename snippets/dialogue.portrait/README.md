# Портрет говорящего

Портрет и выражение для говорящего: «говорящий:эмоция=картинка»; показывает узел-картинку.

Поля:

- `portraits` (list) — Портреты (имя:эмоция=путь)
- `position` (vec2) — Позиция на экране
- `size` (vec2) — Размер

## Изменения 1.0.1

Портрет переведён на RmlUi image; line получает прямой payload.
Схема полей совместима с 1.0.0; миграция значений не требуется.
Проверки приёмки — `docs/SNIPPET_PROGRESS.md` в репозитории движка.

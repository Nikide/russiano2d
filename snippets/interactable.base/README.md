# Интерактивный объект

Действие по клавише рядом с объектом: подсказка, условие доступности и событие.

Поля:

- `action` (string) — Событие действия
- `prompt` (string) — Подсказка
- `key` (string) — Клавиша
- `radius` (number) — Радиус
- `actor` (entity) — Кто действует
- `requires` (string) — Условие (ключ данных у actor)

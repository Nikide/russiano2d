# Миграция сейва

Версия данных сейва и декларативные миграции: переименование ключей и значения по умолчанию ($.save.schema).

Поля:

- `version` (int) — Версия данных
- `namespace` (string) — Пространство
- `renames` (list) — Переименования (версия:старый=новый)
- `defaults` (list) — По умолчанию (ключ=число)

# Граната

Бросок гранаты с физическим телом: отскоки и взрыв по таймеру.

Поля:

- `key` (string) — Клавиша
- `throw` (vec2) — Бросок (вперёд, вверх)
- `fuse` (int) — Задержка
- `radius` (number) — Радиус взрыва
- `damage` (number) — Урон
- `targets` (string) — Цели
- `cooldown` (int) — Перезарядка

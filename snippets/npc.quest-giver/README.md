# Квестодатель

Выдаёт задание $.quest по клавише и принимает готовое.

Поля:

- `quest` (string) — ID задания
- `actor` (entity) — Кто взаимодействует
- `radius` (number) — Радиус
- `key` (string) — Клавиша

## Изменения 1.0.1

Кэш actor передаётся в nearPress; после удаления цели селектор разрешается заново.
Схема полей совместима с 1.0.0; миграция значений не требуется.
Проверки приёмки — `docs/SNIPPET_PROGRESS.md` в репозитории движка.

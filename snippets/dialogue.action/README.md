# Действие из диалога

Выбор варианта или реплика диалога ставит флаг и шлёт игровое событие: «текст или id реплики=событие».

Поля:

- `dialog` (string) — ID диалога
- `actions` (list) — Действия (вариант/реплика=событие)
- `setFlag` (string) — Ставить флаг = выбор

## Изменения 1.0.1

Обработчики $.dialog.on читают прямой payload; глобальные события сохраняют e.data.
Схема полей совместима с 1.0.0; миграция значений не требуется.
Проверки приёмки — `docs/SNIPPET_PROGRESS.md` в репозитории движка.

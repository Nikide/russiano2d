# Луч и зеркала

Луч от источника отражается зеркалами (класс mirror, угол узла) и должен попасть в приёмник.

Поля:

- `direction` (vec2) — Направление луча
- `mirrors` (string) — Зеркала
- `receiver` (entity) — Приёмник
- `bounces` (int) — Отражений
- `range` (number) — Длина отрезка
- `solvedEvent` (string) — Событие решения

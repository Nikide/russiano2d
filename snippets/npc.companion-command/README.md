# Спутник: команды

Команды спутнику клавишами: следовать, ждать, атаковать ближайшего врага.

Поля:

- `followKey` (string) — Следовать
- `waitKey` (string) — Ждать
- `attackKey` (string) — Атаковать
- `enemies` (string) — Враги
- `speed` (number) — Скорость
- `damage` (number) — Урон
- `cooldown` (int) — Перезарядка удара

Состав / зависимости: `npc.companion-follow`

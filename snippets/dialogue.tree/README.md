# Дерево диалога

Ветвящийся диалог $.dialog из строк реплик; играется событием dialogue:play или пакетами-якорями.

Поля:

- `id` (string) — ID диалога
- `lines` (list) — Реплики (id | говорящий | текст | куда)
- `choices` (list) — Варианты (реплика | текст | куда | флаг)
- `speed` (int) — Скорость печати

# Проверка готовности

Старт матча, только когда все в лобби готовы; иначе старт заблокирован.

Поля:

- `minPlayers` (int) — Минимум игроков
- `startEvent` (string) — Событие старта

Состав / зависимости: `net.lobby`

## Изменения 1.0.1

playerCount учитывает хоста один раз; disconnect снимает готовность peer.
Схема полей совместима с 1.0.0; миграция значений не требуется.
Проверки приёмки — `docs/SNIPPET_PROGRESS.md` в репозитории движка.

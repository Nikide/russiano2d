# Стоимость способности

Ресурс (мана, энергия) с восстановлением; способность тратит cost или отказывает.

Поля:

- `id` (string) — ID способности
- `resource` (string) — Ресурс
- `max` (number) — Максимум
- `regen` (number) — Восстановление
- `cost` (number) — Цена

Состав / зависимости: `ability.base`

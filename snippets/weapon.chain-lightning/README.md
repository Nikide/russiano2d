# Цепная молния

Удар по ближайшей цели перескакивает на соседние с убывающим уроном.

Поля:

- `key` (string) — Клавиша
- `range` (number) — Дальность
- `jump` (number) — Перескок
- `chains` (int) — Целей
- `damage` (number) — Урон
- `falloff` (number) — Убывание
- `cooldown` (int) — Перезарядка
- `targets` (string) — Цели

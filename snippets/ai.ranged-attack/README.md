# Стрельба ИИ

Держит дистанцию до цели и стреляет снарядами.

Поля:

- `target` (entity) — Цель
- `min` (number) — Ближе — отходит
- `max` (number) — Дальше — подходит
- `speed` (number) — Скорость
- `damage` (number) — Урон
- `bulletSpeed` (number) — Скорость снаряда
- `cooldown` (int) — Перезарядка

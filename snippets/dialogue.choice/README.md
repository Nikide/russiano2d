# Выбор в диалоге

Варианты ответа к реплике диалога dialogue.tree с условием-флагом и записью выбора во флаг.

Поля:

- `dialog` (string) — ID диалога
- `line` (string) — Реплика
- `options` (list) — Варианты (текст | куда | флаг-условие)
- `record` (string) — Записать выбор во флаг

Состав / зависимости: `dialogue.tree`

## Изменения 1.0.1

Обработчики $.dialog.on читают прямой payload; глобальные события сохраняют e.data.
Схема полей совместима с 1.0.0; миграция значений не требуется.
Проверки приёмки — `docs/SNIPPET_PROGRESS.md` в репозитории движка.

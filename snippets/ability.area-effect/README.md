# Эффект по площади

При применении способности: урон или лечение всем подходящим в радиусе цели.

Поля:

- `id` (string) — ID способности
- `radius` (number) — Радиус
- `effect` (enum) — Эффект
- `amount` (number) — Величина
- `targets` (string) — Кого
- `type` (string) — Тип урона / статуса

Состав / зависимости: `ability.base`

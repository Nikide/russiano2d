# Переключатель

Переключатель вкл/выкл по interact или клавише; глобальные события вкл и выкл.

Поля:

- `actor` (entity) — Кто взаимодействует
- `radius` (number) — Радиус
- `key` (string) — Клавиша
- `onEvent` (string) — Событие «вкл»
- `offEvent` (string) — Событие «выкл»
- `once` (bool) — Один раз

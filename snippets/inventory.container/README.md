# Контейнер

Сундук или тайник со своим $.inv; по клавише рядом — событие container:open с двумя списками.

Поля:

- `actor` (entity) — Кто взаимодействует
- `radius` (number) — Радиус
- `key` (string) — Клавиша
- `cols` (int) — Колонок
- `rows` (int) — Рядов
- `contents` (list) — Содержимое (id=число)

# Режиссёр волн

Волны противников: число растёт от волны к волне, следующая — когда текущая убита.

Поля:

- `prefab` (string) — Prefab врага
- `first` (int) — В первой волне
- `growth` (number) — Рост за волну
- `waves` (int) — Волн (0 — бесконечно)
- `pause` (int) — Пауза между волнами
- `area` (string) — Зона появления (x, y, ш, в)

# Дробовик

Дробовик в $.weapons: дробь, разброс, поштучная перезарядка; выстрел — через weapon.hitscan/spread.

Поля:

- `weapon` (string) — ID ствола
- `damage` (number) — Урон дробины
- `pellets` (int) — Дробин
- `spread` (number) — Разброс
- `shells` (int) — Патронов
- `reload` (number) — Перезарядка
- `key` (string) — Клавиша выстрела

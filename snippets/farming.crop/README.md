# Грядка

Посев семенем из инвентаря, рост по стадиям с поливом, сбор урожая в инвентарь.

Поля:

- `actor` (entity) — Кто взаимодействует
- `radius` (number) — Радиус
- `key` (string) — Клавиша
- `seed` (string) — Семя (id предмета)
- `harvest` (string) — Урожай (id)
- `yield` (int) — Урожай, шт.
- `growMs` (int) — Время роста
- `stages` (int) — Стадий
- `needsWater` (bool) — Нужен полив

## Изменения 1.0.1

Кэш actor передаётся в nearPress; после удаления цели селектор разрешается заново.
Схема полей совместима с 1.0.0; миграция значений не требуется.
Проверки приёмки — `docs/SNIPPET_PROGRESS.md` в репозитории движка.

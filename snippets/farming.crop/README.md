# Грядка

Посев семенем из инвентаря, рост по стадиям с поливом, сбор урожая в инвентарь.

Поля:

- `actor` (entity) — Кто взаимодействует
- `radius` (number) — Радиус
- `key` (string) — Клавиша
- `seed` (string) — Семя (id предмета)
- `harvest` (string) — Урожай (id)
- `yield` (int) — Урожай, шт.
- `growMs` (int) — Время роста
- `stages` (int) — Стадий
- `needsWater` (bool) — Нужен полив

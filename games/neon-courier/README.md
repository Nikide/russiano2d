# Неоновый курьер

Небольшая законченная аркада, созданная для проверки рабочего процесса Russiano2D SDK.
Соберите шесть золотых посылок и вернитесь на зелёную базу за 75 секунд.
Розовые дроны снимают заряд щита; после попадания есть 1,5 секунды неуязвимости.
Три попадания или истечение времени заканчивают рейс.

- WASD / стрелки — движение.
- Escape / кнопка «Пауза» — пауза и продолжение.
- R — новый рейс.
- Меню, победа и поражение позволяют начать заново мышью.

Из корня репозитория:

```sh
./build/r2d-sdk run games/neon-courier
./build/r2d-sdk build games/neon-courier --out build/neon-courier --no-encrypt
./build/neon-courier
```

В SDK (`./build/russiano2d --game sdk`) откройте каталог `games/neon-courier`.
`controls.input.json` редактируется Input Tools, `pickup.particles.json` — Particle Studio,
`ui/*.rml` / `ui/game.rcss` — RmlUi Studio; код игры — `main.js`.
Проект создан кнопкой шаблона blank в SDK. Управление сохранено Input Tools;
эффект подбора проверен в Particle Studio с изменением, undo/redo и сохранением.
Запуск и Package выполнены через оболочку SDK. Код написан как обычный текст:
SDK по философии не собирает gameplay визуальным редактором.

Игра использует только публичный `$`, обычные узлы, систему частиц R2D и RmlUi.
Шрифт Open Sans и его лицензия включены в проект для автономной сборки.
Ассеты не требуют SDK, Python или Node.js при запуске.

Проверка: `python3 tests/agent/neon_courier_test.py`. Она проверяет реальную мышь,
движение, паузу, повреждения, таймер, перезапуск, победу целиком клавиатурой,
а также сборку SDK и запуск в пустом временном каталоге.

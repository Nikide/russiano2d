# Отклонено: помощник по `$` API (r2d-help)

Здесь лежит работа по CLI-помощнику `r2d-help` — поиск по реестру API и
документации движка через BM25 и эмбеддинги (llama.cpp + multilingual-e5-small).
Перенесено из рабочего дерева 2026-10-10 по решению владельца проекта.

## Что здесь

| Было в проекте | Теперь здесь | Что это |
|---|---|---|
| `sdk/help/` | `sdk-help/` | код помощника: `help_main.c`, `help_index.c`, `help_corpus.c`, `help_embed.c`, `help.h`, `CMakeLists.txt` |
| `tools/help_train/` | `tools-help_train/` | обучение и конвертация: `run.sh`, `docker.sh`, `train.py`, `convert_e5.py`, `check_gguf.py`, `pairs.tsv`, `r2d-help.patch` |
| `docs/HELP.md` | `HELP.md` | полное описание помощника: команды, индекс, модель, замеры, ограничения |
| `tests/help_eval.py` | `help_eval.py` | замер качества: recall@1, recall@5, MRR |
| `tests/sdk/help_test.c` | `help_test.c` | тест без модели: токенизатор, формат индекса, BM25, сбор корпуса |
| `tests/fixtures/help/queries.json` | `fixtures-help/queries.json` | 50 вопросов с ожидаемыми именами API |

## Что отвязано в проекте

Чтобы движок и SDK собирались как прежде, убраны:

* `CMakeLists.txt` — `add_subdirectory(sdk/help)`;
* `tools/ci_verify.py` — запуск `r2d_help_test` в проверке;
* `tools/release.py` — упаковка `r2d-help`, `r2d-help.idx`, `r2d-help.gguf` в релизы;
* `sdk/native/sdk_util.c` — флаги `--top`, `--index`, `--threads` помощника
  (`--model` оставлен: им пользуется `r2d-sdk bake-re2d`);
* `docs/SDK.md` — строка про помощника в таблице частей SDK.

## Что сюда НЕ входит

Агентский режим движка (`--agent`, `--headless`) остался на месте: `src/agent.c`,
`tests/agent/` (124 файла — это основной автоматизированный набор тестов
движка), `docs/AGENT_API.md`, `tools/agent_client.py`, `$ .agent` в демо.
Его перенос лишил бы проект тестирования, поэтому он не тронут.

## Как вернуть

Помощник самодостаточен и собирался отдельной целью. Возврат — это обратный
`git mv` файлов на прежние места плюс восстановление пяти перечисленных точек
подключения.

# dsh-russiano2d-docs-gate

Плагин DeepSeek Harness для этого репозитория: агент **не пишет в движок, пока не
прочитал его документацию** — сначала философию, потом правила агентов, потом
низкоуровневые доки, потом высокоуровневые.

| Шаг | Документ | Что это |
|---|---|---|
| 1 | `docs/ARCHITECTURE.md` | Архитектура и философия API `$` |
| 2 | `docs/AGENT_IMPLEMENTATION_RULES.md` | Правила для кодинг-агентов: рабочий цикл, стоп-условия, закон UI |
| 3 | `docs/internal/NATIVE.md` | Низкоуровневые вызовы `engine.*` |
| 4 | `docs/HIGH_LEVEL_API.md` | Высокоуровневое API `$` |
| + | `docs/highlevel/_CONTRACT.md` | только при правке `src/highlevel/**` |
| + | `docs/highlevel/<имя>.md` | только при правке `src/highlevel/<имя>.js` |

Документ считается прочитанным, только если покрыты его строки: `read` с
`offset`/`limit` можно вызывать несколько раз, диапазоны складываются, но
недочитанный файл гейт не открывает. `bash cat` вместо `read` не засчитывается.

## Что делает плагин

1. **Секция системного промпта** `russiano2d:docs-gate` — обязательный порядок и
   прогресс именно этой сессии. В каталоге, который не является репозиторием
   движка, секция пустая.
2. **Страж в реестре инструментов** (`ctx.tools.guard`) — глобальный, поэтому
   действует и на сабагентов, и на тимейтов, и на детей workflow: делегирование
   правило не отменяет.
3. **Учёт чтения** по результатам инструмента `read` (событие `tools/result`),
   отдельно для каждой сессии.

Пока гейт закрыт, отклоняются:

* `write`, `edit`, `str_replace_editor` — если цель лежит внутри корня движка;
* `bash`/`pwsh` — если команда меняет файлы: `>`/`>>`, `tee`, `sed -i`, `perl -i`,
  `patch`, `git apply`, `git restore`, `truncate`, `dd`, `rm`, `mv`, `cp`,
  `mkdir`, `touch`, `ln`.

Не блокируются: чтение и поиск (`read`, `grep`, `glob`), сборка (`cmake`, `ninja`),
тесты, `git status`, команды с выводом в `/dev/null`, установка зависимостей,
запись **вне** корня движка.

Отказ приходит как обычная ошибка инструмента с готовой инструкцией:

```
Russiano2D: правка «src/highlevel/fx.js» заблокирована, пока не прочитана документация движка.

Обязательный порядок (сначала философия, потом низкоуровневые доки, потом высокоуровневые):
✅ 1. docs/ARCHITECTURE.md — Архитектура и философия API `$`
⬜ 2. docs/internal/NATIVE.md — Низкоуровневые вызовы `engine.*`
⬜ 3. docs/HIGH_LEVEL_API.md — Высокоуровневое API `$`
⬜ 4. docs/highlevel/_CONTRACT.md — Контракт модуля подсистемы `$`
⬜ 5. docs/highlevel/fx.md — Подсистема `fx` в высокоуровневом API

Сейчас читай: read file_path="docs/internal/NATIVE.md" limit=2000
Читать нужно целиком и по порядку; bash `cat` вместо read не засчитывается.
После этого повтори ровно тот же вызов инструмента write.
```

## Установка в профиль

Плагин — локальный бандл Cordis. Ставится в профиль как `link:`-зависимость:

```sh
dsh plugin --profile web add "/Volumes/SSD NVME/nikiniki2d/tools/dsh-russiano2d-docs-gate"
```

После установки перезапустите `dsh web` (или переключите бандл в Plugins) — новый
хост-плагин загружается при старте композиции. Удаление:

```sh
dsh plugin --profile web remove dsh-russiano2d-docs-gate
```

## Настройка

Настройки строки бандла (поле `config` в `cordis.patch.yml` профиля, строка
`id: russiano2d-docs-gate`):

| Поле | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `true` | полный выключатель |
| `rootMarkers` | `docs/ARCHITECTURE.md`, `docs/internal/NATIVE.md`, `docs/HIGH_LEVEL_API.md` | все файлы должны быть в каталоге, чтобы он считался корнем движка |
| `docs` | триада выше | обязательные документы: `{ id, path, title, minCoverage? }` |
| `conditionalDocs` | `_CONTRACT.md` при `src/highlevel/` | `{ id, path, title, whenPrefix }` |
| `moduleDocs` | включено | `src/highlevel/<имя>.js` требует `docs/highlevel/<имя>.md`, если он есть |
| `minCoverage` | `1` | доля строк документа, которую нужно прочитать |
| `writeTools` | `write`, `edit`, `str_replace_editor` | инструменты прямой записи |
| `shellTools` | `bash`, `pwsh` | инструменты-оболочки |
| `shellMutationPatterns` | список из `policy.cjs` | `{ id, source }` — регулярки «команда меняет файлы» |
| `sectionOrder` | `950` | место секции в системном промпте (до `TOOL_BASH` = 1000) |
| `maxRootWalk` | `12` | на сколько уровней вверх искать корень |

Список документов, шаблоны и тексты отказов лежат в `lib/policy.cjs` и
перечитываются с диска при каждой загрузке композиции: правка `policy.cjs`
подхватывается переключением бандла, без пересборки. Сам `lib/gate.js` —
стабильный загрузчик: если меняете его, смените имя файла и поправьте
`package.json` (Node кэширует модуль по URL).

## Проверка

```sh
node --test tools/dsh-russiano2d-docs-gate/tests/gate.test.mjs
```

16 тестов: распознавание корня движка, шаблоны команд, состав обязательных
документов, покрытие строк, отказ и разблокировка через `apply()`, пустая секция
промпта вне движка, сброс состояния при закрытии сессии.

## Ограничения

* Состояние чтения живёт в памяти процесса и привязано к сессии. После
  перезапуска приложения или пересоздания сессии документы нужно прочитать заново.
* Каждый агент (включая сабагента и тимейта) читает документацию сам: знание
  родителя детям не передаётся.
* Определение «команда меняет файлы» — эвристика по регулярным выражениям.
  Экзотическая запись может проскочить; необычная read-only команда может
  попасть под отказ — тогда её лечат правкой `shellMutationPatterns` или
  `enabled: false` на время.

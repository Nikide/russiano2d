# dsh-russiano2d-docs-gate

Плагин DeepSeek Harness для этого репозитория. Две доктрины, ровно две:

1. **Сначала философия — потом работа.** Агент не пишет в движок, пока не прочитал
   целиком `docs/PHILOSOPHY.md` — конституцию движка. Это всё, что нужно перед
   первой правкой; остальные доки движка гейт не ждёт.
2. **ГЛАВНЫЙ ГЕЙТ: движок только 2D.** Превращать Russiano2D в 3D нельзя
   (`docs/PHILOSOPHY.md` §3). Правка, вводящая 3D-сущность, отклоняется стражем.

| Что | Документ | Роль |
|---|---|---|
| Гейт | `docs/PHILOSOPHY.md` | читается целиком, инструментом `read`; без него запись отклоняется |
| Ссылки | `docs/ARCHITECTURE.md` (философия API `$`) | в промпте, запись не блокируют |
| Ссылки | `docs/AGENT_IMPLEMENTATION_RULES.md` (правила агентов) | — « — |
| Ссылки | `docs/internal/NATIVE.md` (нативное ядро `engine.*`) | — « — |
| Ссылки | `docs/HIGH_LEVEL_API.md` (высокоуровневое API `$`) | — « — |
| Ссылки | `docs/UI_RMLUI_LAW.md`, `docs/highlevel/_CONTRACT.md`, `docs/highlevel/<имя>.md` | — « — |

Документ считается прочитанным, только если покрыты его строки: `read` с
`offset`/`limit` можно вызывать несколько раз, диапазоны складываются, но
недочитанный файл гейт не открывает. `bash cat` вместо `read` не засчитывается.

## Что делает плагин

1. **Секция системного промпта** `russiano2d:docs-gate` — обе доктрины и прогресс
   чтения именно этой сессии. В каталоге, который не является репозиторием
   движка, секция пустая.
2. **Страж в реестре инструментов** (`ctx.tools.guard`) — глобальный, поэтому
   действует и на сабагентов, и на тимейтов, и на детей workflow: делегирование
   правило не отменяет.
3. **Учёт чтения** по результатам инструмента `read` (событие `tools/result`),
   отдельно для каждой сессии.

Пока философия не прочитана, отклоняются:

* `write`, `edit`, `str_replace_editor` — если цель лежит внутри корня движка;
* `bash`/`pwsh` — если команда меняет файлы: `>`/`>>`, `tee`, `sed -i`, `perl -i`,
  `patch`, `git apply`, `git restore`, `truncate`, `dd`, `rm`, `mv`, `cp`,
  `mkdir`, `touch`, `ln`.

Не блокируются: чтение и поиск (`read`, `grep`, `glob`), сборка (`cmake`, `ninja`),
тесты, `git status`, команды с выводом в `/dev/null`, установка зависимостей,
запись **вне** корня движка.

Отказ приходит как обычная ошибка инструмента с готовой инструкцией:

```
Russiano2D: правка «src/highlevel/fx.js» заблокирована, пока не прочитана философия движка.

Сначала философия — потом работа: читается целиком, инструментом read.
⬜ 1. docs/PHILOSOPHY.md — Философия Russiano2D — конституция движка: 2D, константы, non-goals

Сейчас читай: read file_path="docs/PHILOSOPHY.md" limit=2000
Читать нужно целиком; bash `cat` вместо read не засчитывается.
После этого повтори ровно тот же вызов инструмента write.
```

## ГЛАВНЫЙ ГЕЙТ: движок только 2D

Действует **всегда** — и до, и после чтения философии. Отклоняется правка, в
которой нашлась 3D-сущность:

* **имя пути**: `render3d.c`, `mesh3d.js`, `r3d/`, `camera3d.js`, `physics3d.c`, …;
* **имя архитектуры в коде**: `R3D`, `Scene3D`, `Node3D`, `Mesh3D`, `World3D`,
  `Transform3D`, `Vector3`, `Matrix4`, `Quaternion`, `MeshRenderer`,
  `Physics3D`, `CharacterBody3D`, `RigidBody3D`, `CollisionShape3D`, `Camera3D`,
  `tinygltf`, `cgltf`, `assimp`, `glm::`, three.js.

Почему: PHILOSOPHY.md §3 перечисляет 3D-сцену, универсальный world mesh API,
3D-физику и общий фреймворк R2D/R3D как явные non-goals — «не должно появляться
попутно».

**Что разрешено и остаётся 2D.** RE2D — это `spatial description → projection →
ordinary 2D representation` (PHILOSOPHY.md §1): XYZ/поверхности/кости/depth —
промежуточные authoring/runtime-данные синтеза, результат — обычный 2D-спрайт или
кадр для существующего R2D-батча. `z`-буфер, `depth`, `submitMesh`, `$.re2dWorld`,
`.kind(Re2D)` — не 3D-рендерер и под гейт не попадают. Импорт 3D-моделей живёт
только в SDK (`r2d-sdk bake-re2d*`): рантайм читает готовый PNG/JSON, меш в игру не
попадает.

**Из гейта исключены** (`law2d.allowedPrefixes`): `docs/`, `sdk/`, `tools/`,
`tests/`, `dist*/`, `build*/`, `build-web/`, `site/`. Там 3D-упоминания законны —
это документация, импортёр SDK, инструменты сборки и дистрибутив.

**Удаление — не 3D-изация.** Команда, которая только удаляет файлы (`rm`,
`rmdir`, `git rm`) и ничего не пишет, под главный гейт не попадает: `rm
src/render3d.c` возвращает движок к 2D. Но `cp`, `>`, `>>`, `tee`, `sed -i` и
прочая запись — уже под гейт.

Отказ главного гейта:

```
Russiano2D: правка «src/render3d.c» отклонена главным гейтом — движок только 2D.

Что нашлось: в имени пути «src/render3d.c» — имя пути с 3D-сущностью (render3d, mesh3d, r3d, 3d, …).

Превращать Russiano2D в 3D нельзя (docs/PHILOSOPHY.md §3, «Явные non-goals»): …
Если задача на самом деле 2D — переформулируй её без 3D-сущностей и повтори
ровно тот же вызов инструмента write.
Если это ложное срабатывание — остановись и вынеси вопрос владельцу проекта
(или внеси путь в `law2d.allowPaths` в конфиге плагина).
```

## Установка в профиль

Плагин — локальный бандл Cordis. Ставится в профиль как `link:`-зависимость
(в этом репозитории он уже стоит в профиле `desktop`):

```sh
dsh plugin --profile desktop add "/Volumes/SSD NVME/nikiniki2d/tools/dsh-russiano2d-docs-gate"
```

После установки перезапустите `dsh` (или переключите бандл в Plugins) — новый
хост-плагин загружается при старте композиции. Удаление:

```sh
dsh plugin --profile desktop remove dsh-russiano2d-docs-gate
```

## Настройка

Настройки строки бандла (поле `config` в `cordis.patch.yml` профиля, строка
`id: russiano2d-docs-gate`):

| Поле | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `true` | полный выключатель |
| `rootMarkers` | `docs/PHILOSOPHY.md`, `docs/ARCHITECTURE.md` | все файлы должны быть в каталоге, чтобы он считался корнем движка |
| `docs` | `docs/PHILOSOPHY.md` | обязательные документы: `{ id, path, title, minCoverage? }` |
| `minCoverage` | `1` | доля строк документа, которую нужно прочитать |
| `references` | список доков движка | справочники в промпте: `{ path, note }`, запись не блокируют |
| `writeTools` | `write`, `edit`, `str_replace_editor` | инструменты прямой записи |
| `shellTools` | `bash`, `pwsh` | инструменты-оболочки |
| `shellMutationPatterns` | список из `policy.cjs` | `{ id, source }` — регулярки «команда меняет файлы» |
| `sectionOrder` | `950` | место секции в системном промпте (до `TOOL_BASH` = 1000) |
| `maxRootWalk` | `12` | на сколько уровней вверх искать корень |
| `hintLimit` | `2000` | максимум строк в подсказке «читай сейчас» |
| `law2d.enabled` | `true` | выключатель главного гейта (гейт философии остаётся) |
| `law2d.allowedPrefixes` | `docs/`, `sdk/`, `tools/`, `tests/`, `dist*/`, `build*/`, `site/` | где 3D-упоминания законны |
| `law2d.allowPaths` | `[]` | точечные исключения-пути (спорный легаси-файл) |
| `law2d.scanExtensions` | `.c .h .cpp .js .mjs .py .json .yml …` | расширения, у которых проверяется содержимое |
| `law2d.pathPatterns` | `{ id, source, flags?, what? }` | запрещённые имена путей |
| `law2d.contentPatterns` | `{ id, source, what? }` | запрещённые имена архитектуры в коде |
| `law2d.removePatterns` | `rm`, `rmdir`, `git rm` | команды, которые только удаляют |
| `law2d.writeGuardPatterns` | `>`, `tee`, `sed -i`, `cp`, `mkdir`, … | признаки записи: отменяют «только удаление» |

Список документов, шаблоны и тексты отказов лежат в `lib/policy.cjs` и
перечитываются с диска при каждой загрузке композиции: правка `policy.cjs`
подхватывается переключением бандла, без пересборки. Сам `lib/gate.js` —
стабильный загрузчик: если меняете его, смените имя файла и поправьте
`package.json` (Node кэширует модуль по URL).

## Проверка

```sh
node --test tools/dsh-russiano2d-docs-gate/tests/gate.test.mjs
```

26 тестов: распознавание корня движка, шаблоны команд, состав обязательных
документов, покрытие строк, отказ и разблокировка через `apply()`, пустая секция
промпта вне движка, сброс состояния при закрытии сессии, а также главный гейт:
запрещённые имена и содержимое, освобождённые зоны, выключатель и `allowPaths`.

Отдельный тест — **калибровка**: он прогоняет правила главного гейта по всему
существующему коду движка (`src/`, `game/`, `demos/`) и требует нуля срабатываний.
Если он падает — либо в репозиторий попала 3D-сущность, либо шаблон слишком
широкий.

## Ограничения

* Состояние чтения живёт в памяти процесса и привязано к сессии. После
  перезапуска приложения или пересоздания сессии философию нужно прочитать заново.
* Каждый агент (включая сабагента и тимейта) читает философию сам: знание
  родителя детям не передаётся.
* Определение «команда меняет файлы» и «в правке есть 3D» — эвристика по
  регулярным выражениям. Смысловая часть правила («не превращать движок в 3D»)
  живёт в доктрине промпта и в `docs/PHILOSOPHY.md`; страж ловит имена, а не
  намерения. Экзотическая запись может проскочить, а необычная 2D-правка с
  неудачным именем — попасть под отказ; лечится правкой `law2d` или
  `enabled: false` на время.
* Гейт смотрит только правки внутри корня движка: за пределами рабочего каталога
  он молчит.

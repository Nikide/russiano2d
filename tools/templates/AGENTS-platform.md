# Russiano2D {{VERSION}} — {{PLATFORM_TITLE }}: инструкция для ИИ-агента

Здесь лежит движок `{{BINARY}}`. Документации рядом нет: **она уже внутри
бинарника**, достаётся командой `{{BINARY}} docs`. Работай по ней, а не по памяти:
`$` API большой и меняется между версиями.

## Как достать документацию

```bash
{{RUN}} docs list                       # все страницы: путь, заголовок, размер (JSON)
{{RUN}} docs show HIGH_LEVEL_API        # страница целиком (имя без docs/ и .md)
{{RUN}} docs show highlevel/camera      # справочник подсистемы $.camera
{{RUN}} docs search тряска              # поиск по слову (одно слово)
{{RUN}} docs context "как сделать прыжок"   # куски доков, кирпичики и API под вопрос
{{RUN}} docs api '$.camera.shake'       # точная сигнатура одного имени `$`
```

Ответы — JSON (`"ok": true`), текст страницы в поле `text`. Начни с
`docs show AGENT_IMPLEMENTATION_RULES`, потом `docs show HIGH_LEVEL_API`.
Полная схема `$` лежит рядом: `api.schema.json` и `russiano2d.d.ts`.

## Прежде чем писать игру

1. Найди нужное имя: `docs api` или `docs context`, не выдумывай `$.…`.
2. Готовые кирпичики и рецепты ищет `{{RUN}} docs context "что хочу сделать"`.
3. После правок: `{{RUN}} lint <проект>` и `{{RUN}} validate <проект>`; ошибки
   имеют стабильные коды (`R2D001`…), `--json` даёт машинный вид.

## Режим агента

Игру можно вести программно: движок читает JSON-команды со stdin и отвечает
JSON-строками. Кадры идут только по команде `step`, прогон воспроизводим.

```bash
{{RUN}} --agent --headless --fixed-dt 0.0166666667
```

Команды (`state`, `eval`, `step`, `screenshot`, `key`, `keys`, `mouse`, `quit` и
другие), параметры и ответы описаны в `{{RUN}} docs show AGENT_API`.

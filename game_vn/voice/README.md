# Озвучка Руси-тян

Реплик героини: **49**. Нарация (6 строк) не озвучивается — это голос за кадром.

## Как записать

1. Взять **`lines_for_minimax.txt`** — реплики через паузу `<#2.5#>` (MiniMax
   вставляет по ней тишину, а нарезка получает готовые границы).
   Если модель прочитает маркеры вслух — брать `lines_clean.txt` без них.
2. Сгенерировать голос одним файлом (MiniMax, `speech-2.8-hd`, тембр вроде
   «Calm Woman»).
3. Нарезать и разложить по репликам одной командой:

   ```bash
   python3 tools/vn_voice_slice.py --audio ~/Downloads/rusi.mp3
   ```

   Инструмент сам найдёт паузы, сверит их число с числом реплик и напишет
   `tl3.mp3`, `tl4.mp3`, … в эту папку. Не совпало — ничего не запишет и
   покажет таблицу, что подкрутить (`--min-silence`).

Если реплики генерируются по одной — сохраняй сразу под именем из таблицы.

## Почему имена такие

Движок ищет озвучку по id реплики в таймлайне: `<dir>/<id>.mp3`
(см. `voice` в `demos/russi_vn/index.js` и `$.timeline.lines()` в
`docs/highlevel/timeline.md`). Так соответствие «реплика ↔ файл» не нужно
хранить отдельной таблицей: переименовал файл — реплика замолчала, и это видно сразу.
